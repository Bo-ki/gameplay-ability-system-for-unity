## 完整规则列表

### SYS: World/System/SystemGroup

| 编号 | 规则摘要 |
|---|---|
| `SYS-01` | 权威计算落在 ECS System/Job 数据流，禁止托管 manager 驱动 |
| `SYS-02` | SystemGroup 是 phase owner，禁止手写 Tick 顺序 |
| `SYS-03` | 系统数量是成本源，避免不必要的 system 拆分 |
| `SYS-04` | Core/Physics/Presentation 成本分组统计 |
| `SYS-05` | World 边界：Debugger/Demo/Presentation 只能通过 Boundary 观察 Core |

### QRY/JOB: 查询与 Job

| 编号 | 规则摘要 |
|---|---|
| `QRY-01` | Hot path 优先 job 化；SystemAPI.Query 限于小规模/debug |
| `QRY-02` | Query contract 写清 All/Any/None/Disabled/ChangeFilter |
| `QRY-03` | Optional 分支用 chunk 级判断，不为每个组合创建 system |
| `QRY-04` | 高频 random lookup 重构为 owner-local 或 chunk-local |
| `JOB-01` | 并行批处理说明 IJobEntity/IJobChunk/主线程选择理由 |
| `JOB-02` | 区分 job scheduling overhead、main-thread sync、Burst warmup |
| `JOB-03` | 不使用 EntityIndexInQuery 作为 hot path 高频操作 |
| `JOB-04` | IJobEntity 的 Execute 参数明确 ref/in 语义 |

### SC/ECB/EN: 结构变化

| 编号 | 规则摘要 |
|---|---|
| `SC-01` | Hot path 不直接结构变化；集中在 mutation phase/ECB playback |
| `SC-02` | 结构变化后重取所有 handle |
| `SC-03` | 批量同类变化优先 EntityQuery bulk |
| `ECB-01` | ECB 是延迟结构变化工具，不是 gameplay event bus |
| `ECB-02` | AppendToBuffer 前确保 buffer 已存在 |
| `ECB-03` | ECB playback 位置属于明确 SystemGroup phase |
| `ECB-04` | ECB allocator 在 playback 后 rewind，不持有其分配的内存 |
| `EN-01` | 高频开关优先 Enableable，低频生命周期再考虑 Add/Remove |
| `EN-02` | Enableable 查询成本和同步等待进入性能诊断 |
| `EN-03` | Random-access Enableable 方法有额外开销；迭代优先 |

### BUF/STORE: Buffer 与 Store

| 编号 | 规则摘要 |
|---|---|
| `BUF-01` | DynamicBuffer 声明容量策略和 externalized 监控 |
| `BUF-02` | 单一全局 buffer 限于 proof/低量；不做百万实体 fan-in |
| `BUF-03` | Buffer handle 结构变化后必须重取 |
| `BUF-04` | InternalBufferCapacity 按实际容量需求设定 |
| `STORE-01` | Store 命名表达 owner、生命周期、索引方式 |
| `STORE-02` | 影响 battle hash 的输出 deterministic |
| `STORE-03` | Store 选型按数据性质分类：gameplay/transient/telemetry/presentation |

### NAT/MAT: 容器与数学

| 编号 | 规则摘要 |
|---|---|
| `NAT-01` | NativeContainer 说明 allocator owner、生命周期、dispose/rewind 位置 |
| `NAT-02` | 影响 battle hash 的结果不用无序 ParallelWriter |
| `NAT-03` | NativeStream 适合并行 fan-in；定义 merge 顺序和内存预算 |
| `NAT-04` | Persistent 容器有明确 owner entity/system 和 teardown |
| `NAT-05` | Allocator 指标进入 Debugger；GC-free ≠ allocation-free |
| `MAT-01` | Runtime Core 不用 UnityEngine.Random |
| `MAT-02` | Random state 按 owner/battle/frame 明确归属 |
| `MAT-03` | 角度单位显式写 radians/degrees |
| `MAT-04` | 矩阵/quaternion 乘法用 math.mul |
| `MAT-05` | Replay/battle hash 记录随机种子和消耗策略 |

### FSM: 状态机与数据分支策略

| 编号 | 规则摘要 |
|---|---|
| `FSM-01` | 高频状态切换禁用 Tag Component add/remove；用 Enableable 或 enum/bit field |
| `FSM-02` | 状态数 ≤ 5 且每状态工作轻 → 单 job enum/bit field 分支 |
| `FSM-03` | 大量 entity 长期 idle → Enableable 整 chunk 跳过 |
| `FSM-04` | 单 entity 上多 FSM 叠加时评估拆分 entity |
| `FSM-05` | 同 entity 上 > 3 个独立 boolean 状态标记 → 合并为 bit field / enum |
| `FSM-06` | 默认单 job enum 分支；profiler 驱动切换到更复杂方案 |

### PRF: 编写规范与性能陷阱

| 编号 | 规则摘要 |
|---|---|
| `PRF-01` | 禁止用 Entity 表示临时/瞬时状态；用 DynamicBuffer/Enableable 替代 |
| `PRF-02` | 禁止在 Hot Path 直接执行结构变化 |
| `PRF-03` | 禁止用 Tag Component 做高频状态标记；改用 Enableable |
| `PRF-04` | 结构变化必须集中到单一 ECB playback phase |
| `PRF-05` | Hot Path 禁止主线程遍历（SystemAPI.Query foreach） |
| `PRF-06` | 禁止高频 Random Access Lookup；优先 owner-local 数据 |
| `PRF-07` | 避免不必要的 System 拆分 |
| `PRF-08` | 禁止 EntityIndexInQuery 在 Hot Path 使用 |
| `PRF-09` | 注意 Query 操作的 Sync 触发；用 IgnoreFilter/Async 规避 |
| `PRF-10` | 监控 DynamicBuffer 溢出；externalizedRatio > 30% 告警 |
| `PRF-11` | 控制 Prefab 数量；静态定义用 BlobAsset |
| `PRF-12` | 审核 SharedComponent 使用；满足三条件才使用 |
| `PRF-13` | 确定性输出不得依赖无序写入 |
| `PRF-14` | NativeContainer 必须明确 Allocator 归属和生命周期 |
| `PRF-15` | Mathematics.Random 状态显式归属；不用 UnityEngine.Random |
| `PRF-16` | System 创建依赖用 CreateAfter；ISystem 优于 SystemBase |
| `PRF-17` | 禁止使用 IAspect（已废弃 API）；统一替代为直接 component 访问 |
| `PRF-18` | LocalToWorld 在 SimulationSystemGroup 可能过期；用 ComputeWorldTransformMatrix |
| `PRF-19` | ComponentLookup/BufferLookup 随机访问与遍历数据重叠导致竞态 |
| `PRF-20` | IJobEntity Execute 参数与 EntityQuery 不匹配的未保护安全风险 |
| `PRF-21` | ExclusiveEntityTransaction 仅限 secondary/streaming World；Runtime Core job 结构变化默认 ECB |
| `PRF-22` | IJobChunk 中 Enableable Mask 处理 — ChunkEntityEnumerator 或 assert !useEnabledMask |
| `PRF-23` | 禁止从 Job 内部启动新 Job（含 .Run() 内嵌） |
| `PRF-24` | 禁止逐 Component 构建 Entity Archetype — 预创建 Archetype 批量创建 |
| `PRF-25` | 每个并行 Job 使用独立 ECB — 避免 sortKey 域重叠导致命令交错 |
| `PRF-26` | 读写数据分离到不同 Component — 避免响应式系统误触发 |
| `PRF-27` | 禁止手动调用其他数据处理 System 的 Update() — 破坏变更版本号 |
| `PRF-28` | 禁止直接修改 Child / PreviousParent — 由 ParentSystem 管理，通过 Parent component 建立层级 |
| `PRF-29` | Singleton API 不自动完成 Job 依赖 — GetSingletonRW 需手动 CompleteDependency 或用 NativeContainer |
| `PRF-30` | `SystemAPI.Query` 中 `DynamicBuffer<T>` 默认读写 — 只读场景需自定义避免不必要 sync point |
| `PRF-31` | ECS Child Buffer 迭代顺序不确定 — 禁止依赖 sibling index 做确定性排序；需确定性时自建排序键 |
| `PRF-32` | 主线程数据操作禁用 `.Run()` Job — `SystemAPI.Query` foreach 无 job dep system 开销；并行才用 `.Schedule()` |
| `PRF-33` | EntityQuery 必须通过 `SystemState.GetEntityQuery` 创建 — 禁止 `EntityManager.CreateEntityQuery`；安全系统无法追踪 |
| `PRF-34` | NativeContainer 放在 IComponentData 上 — 禁止对该 component 调度 IJobChunk/IJobEntity；主线程提取后单独调度 job |

### SEL: GAS Runtime Core API 选型

| 编号 | 规则摘要 |
|---|---|
| `SEL-01` | 数据性质分类优先：Gameplay/Transient/Telemetry/Presentation 分别选型 |
| `SEL-02` | 禁止 proof API 固化为 scale-ready 方案：Singleton Buffer 仅限 proof |

## 引用规范

### 最小引用要求

| 任务类型 | 至少引用 |
|---|---|
| Runtime Core | `SYS-*` `QRY-*` `JOB-*` `SC-*` `BUF-*` `BUR-*` `NAT-*` `FSM-*` `PRF-*` `SEL-*` `ODF-*` |
| Debugger | `DBG-*` `QRY-*` `SC-*` `BUF-*` `BUR-*` `PRF-*` `ODF-*` |
| AutoChessDemo | +`PHY-*`（如启用 Physics）`GFX-*`（如启用 Graphics）`PRF-*` |
| Luban | `BAKE-*` `BLOB-*` `CONTENT-*` `PRF-*` `SEL-*` `ODF-*` |

### 引用格式

```
正确: 根据 SC-01 (03-结构变化-ECB-Enableable)，hot path 不允许直接结构变化
      拒绝 CASE-01 (SystemAPI.Query) 因主线程 sync 不可接受 (参见 02-查询遍历与Job)
      
错误: 根据官方文档，不能做结构变化
      看过 DOTS 文档了
```

只引用编号不够，必须写明采用/拒绝/暂不相关理由。
