# 文档覆盖流程（兼容入口）

> 本文件只保留旧路径兼容，不再维护正文。唯一 owner 是
> [../主题/21-官方文档覆盖与流程闭环.md](../主题/21-官方文档覆盖与流程闭环.md)。

## 使用规则

1. DOTS 官方依据如何进入行动报告、`00`、`01`、`02`、`04`，统一读取 `主题/21-官方文档覆盖与流程闭环.md`。
2. 不要在本文件补充新的 `ODF-*` 规则、任务覆盖矩阵或行动报告模板。
3. 如果发现官方文档覆盖流程需要变化，直接修改 `主题/21`，再更新引用入口。

## 迁移原因

旧正文与 `主题/21` 重复维护，容易让执行 Agent 从 `元信息` 入口读取到不同的任务类型矩阵和 ODF 规则。当前文档生成、消费、归档链路以单主题文档为权威，本兼容入口只负责把旧链接导向新 owner。
