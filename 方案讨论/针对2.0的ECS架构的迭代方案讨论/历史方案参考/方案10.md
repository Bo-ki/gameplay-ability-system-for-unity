# EX-GAS 2.0 架构深度分析与重构方案

## 瘦身口径

> 已移除基于 2.0 旧状态的开头问题诊断和明显过时的旧主链对比；保留原始方案中仍可借鉴的架构分层、代码块、图示和实施思路。当前分支事实以 `../00-当前架构事实/README.md` 为准；当前任务路线以 `../02-主线任务树/README.md` 为准；目标态吸收关系以 `../01-目标态架构共识/README.md` 及各 Spec 的 `历史方案定位` 为准。

## 保留的目标态信号

- OOP 层只作为 Shell / Facade：提交命令、读取表现/调试事实，不维护 gameplay 状态。
- 配置链路最终应从 Luban/Excel 收束到稳定的 definition carrier，并逐步走 Blob / generated builder。
- Ability / Attribute / GE 热路径应在语义稳定后向 Burst-friendly、query/ECB/job-friendly 结构收口。
- 事件不应恢复托管回调中心；应分为 simulation fact stream、presentation outbox 和 persistent debug/replay sink。
- 调度顺序需要被显式表达和测试；原文的自动发现代码仅保留为“调度集中化”参考，不作为当前核心调度方案。

## 原始重构架构总览

```
┌──────────────────────────────────────────────────────────────────┐
│  【OOP Shell Layer】 — 纯门面，零运行时状态，零ECS类型泄漏        │
│  AbilitySystemComponent (MonoBehaviour)                          │
│  GASFacade (只持有 Entity，通过 CommandChannel 提交命令)          │
│  GASEventBus (ECS→OOP 的单向事件总线，供UI/网络订阅)             │
└──────────────────────────────────────────────────────────────────┘
                    ↕ CommandChannel (写) / EventBus (读)
┌──────────────────────────────────────────────────────────────────┐

│  Components: CAscCore, CAbilitySlot, CEffectRuntime...           │

│  Jobs: IJobEntity (SIMD/Burst)                                   │
│  GASLogger: 结构化日志，ECS内部可用                              │
└──────────────────────────────────────────────────────────────────┘
                    ↕ BlobAssetReference<T>
┌──────────────────────────────────────────────────────────────────┐
│  【Data Layer】 — Luban → BlobAsset，Burst可访问                 │

│  LubanBlobBuilder: 启动时一次性转换，运行时零GC                  │
└──────────────────────────────────────────────────────────────────┘
```

## 完整代码重构参考

### 3.1 Data Layer：Luban → BlobAsset

**设计信号**：配置数据最终应从托管 authoring 数据转换到稳定的 ECS definition carrier；BlobAsset 是目标态候选。

**重构方案**：启动时将 Luban JSON 转换为 `BlobAsset`，存入 ECS Singleton。

```csharp
// ============================================================
// 文件: Assets/GAS/Runtime/Data/Blob/AbilityBlobAsset.cs
// 职责: 定义 Ability 配置的 BlobAsset 结构
//       Burst Job 可以通过 BlobAssetReference<T> 安全访问
// ============================================================
using Unity.Entities;
using Unity.Collections;

namespace GAS.Runtime.Data
{
    // BlobAsset 内部只能用 BlobArray / BlobString / BlobPtr
    // 不能有托管类型（class, string[]等）
    public struct AbilityConfigBlob
    {
        public int Code;
        public int Level;
        public int CooldownFrames;
        public BlobArray<int> ActivationRequiredTags;  // 激活所需Tag
        public BlobArray<int> ActivationBlockedTags;   // 激活阻断Tag
        public BlobArray<int> ActivationOwnedTags;     // 激活时赋予Tag
        public BlobArray<int> CancelAbilityTags;       // 激活时取消的Ability Tag
        public int CostEffectCode;                     // 消耗GE的Code
        public int CooldownEffectCode;                 // CD GE的Code
    }

    public struct AbilityConfigBlobTable
    {
        public BlobArray<AbilityConfigBlob> Configs;
    }

    // ECS Singleton Component，持有整张Ability配置表的BlobAsset引用
    public struct SAbilityConfigTable : IComponentData
    {
        public BlobAssetReference<AbilityConfigBlobTable> TableRef;
    }
}
```

```csharp
// ============================================================
// 文件: Assets/GAS/Runtime/Data/LubanBlobBuilder.cs
// 职责: 启动时将 Luban 生成的 JSON 数据转换为 BlobAsset
//       这是 Data Layer 和 ECS Core 之间的唯一桥梁
//       只在初始化时执行一次，运行时零GC
// ============================================================
using Unity.Entities;
using Unity.Collections;
using GAS.Runtime.Data;

namespace GAS.Runtime
{
    public static class LubanBlobBuilder
    {
        /// <summary>
        /// 将 XLuban 中的 Ability 配置表转换为 BlobAsset，
        /// 并作为 Singleton 注入 ECS World。
        /// 调用时机：GASManager.Initialize() 内部，Systems 创建之前。
        /// </summary>
        public static void BuildAndInjectAbilityTable(EntityManager em)
        {
            // 从 Luban 获取所有 Ability 配置（托管堆，只在这里用一次）
            var lubanConfigs = XLuban.GetAllAbilityConfigs(); // 现有API

            var builder = new BlobBuilder(Allocator.Temp);
            ref var root = ref builder.ConstructRoot<AbilityConfigBlobTable>();

            var configArray = builder.Allocate(ref root.Configs, lubanConfigs.Count);
            for (int i = 0; i < lubanConfigs.Count; i++)
            {
                var src = lubanConfigs[i];
                configArray[i].Code = src.Code;
                configArray[i].Level = src.Level;
                configArray[i].CooldownFrames = src.CooldownFrames;
                configArray[i].CostEffectCode = src.CostEffectCode;
                configArray[i].CooldownEffectCode = src.CooldownEffectCode;

                // 填充 Tag 数组
                FillBlobArray(ref builder, ref configArray[i].ActivationRequiredTags,
                    src.ActivationRequiredTags);
                FillBlobArray(ref builder, ref configArray[i].ActivationBlockedTags,
                    src.ActivationBlockedTags);
                FillBlobArray(ref builder, ref configArray[i].ActivationOwnedTags,
                    src.ActivationOwnedTags);
                FillBlobArray(ref builder, ref configArray[i].CancelAbilityTags,
                    src.CancelAbilityTags);
            }

            var blobRef = builder.CreateBlobAssetReference<AbilityConfigBlobTable>(Allocator.Persistent);
            builder.Dispose();

            // 注入为 ECS Singleton
            var singletonEntity = em.CreateEntity();
            em.AddComponentData(singletonEntity, new SAbilityConfigTable { TableRef = blobRef });

            GASLogger.Info("[LubanBlobBuilder] AbilityConfigTable built: {0} configs", lubanConfigs.Count);
        }

        private static void FillBlobArray(ref BlobBuilder builder, ref BlobArray<int> dest, int[] src)
        {
            if (src == null || src.Length == 0) return;
            var arr = builder.Allocate(ref dest, src.Length);
            for (int i = 0; i < src.Length; i++) arr[i] = src[i];
        }
    }
}
```

**设计合理性**：BlobAsset 存储在非托管内存中，`BlobAssetReference<T>` 可以安全地传入 Burst Job，彻底解决了配置数据无法在高性能路径中访问的问题。Luban 的价值从"生成常量"升级为"生成ECS数据空间的原材料"。

### 3.2 ECS Core：纯血 Ability System

**设计信号**：Ability 自定义行为应向数据化标识 + 专用 System 收束；本节保留原方案中 Tag Component + ISystem 的目标态代码。

**重构方案**：用 **Tag Component + 专用 System** 替代继承体系。每种 Ability 类型对应一个 `ISystem`，通过 `IAbilityTag` 标记组件区分。

```csharp
// ============================================================
// 文件: Assets/GAS/Runtime/Ability/Component/CAbilityType.cs
// 职责: 用 Tag Component 替代 OOP 继承，标识 Ability 类型
//       这是 ECS 的正确做法：用数据描述行为，而非继承
// ============================================================
using Unity.Entities;

namespace GAS.Runtime
{
    // 每种 Ability 类型是一个独立的 Tag Component
    // 优势：ECS Archetype 自动分组，System 查询零开销
    
    /// <summary>近战普攻 Ability 类型标记</summary>
    public struct CAbilityType_MeleeAttack : IComponentData, IEnableableComponent { }
    
    /// <summary>技能施法 Ability 类型标记</summary>
    public struct CAbilityType_CastSpell : IComponentData, IEnableableComponent { }
    
    /// <summary>冲刺 Ability 类型标记</summary>
    public struct CAbilityType_Dash : IComponentData, IEnableableComponent { }

    // 激活时的运行时参数（纯值类型，Burst 可用）
    public struct CAbilityActivationParam : IComponentData
    {
        public float TargetX;
        public float TargetY;
        public float TargetZ;
        public int TargetEntityIndex; // 目标 Entity.Index
        public int ExtraInt;
    }
}
```

```csharp
// ============================================================
// 文件: Assets/GAS/Runtime/System/Ability/SMeleeAttackAbility.cs
// 职责: 近战普攻 Ability 的纯血 ECS 实现
//       完全 Burst 编译，无托管堆访问
//       目标态信号：用数据标识行为，而不是把行为对象放进 simulation 主链
// ============================================================
using Unity.Burst;
using Unity.Entities;
using Unity.Collections;

namespace GAS.Runtime
{
    [UpdateInGroup(typeof(SGAbility))]
    [BurstCompile] // ← 现在可以加了！
    public partial struct SMeleeAttackAbility : ISystem
    {
        [BurstCompile]
        public void OnCreate(ref SystemState state)
        {
            // 只在有待激活的近战普攻时才运行
            state.RequireForUpdate<CAbilityInTryActivate>();
            state.RequireForUpdate<CAbilityType_MeleeAttack>();
        }

        [BurstCompile]
        public void OnUpdate(ref SystemState state)
        {
            var ecb = new EntityCommandBuffer(Allocator.Temp);
            var globalTimer = SystemAPI.GetSingleton<GlobalTimer>();
            
            // 读取 BlobAsset 配置表（Burst 安全）
            var configTable = SystemAPI.GetSingleton<SAbilityConfigTable>();

            // IJobEntity：并行处理所有待激活的近战普攻
            new ActivateMeleeAttackJob
            {
                ECB = ecb.AsParallelWriter(),
                GlobalTimer = globalTimer,
                ConfigTableRef = configTable.TableRef,
            }.ScheduleParallel();

            state.Dependency.Complete();
            ecb.Playback(state.EntityManager);
            ecb.Dispose();
        }

        [BurstCompile]
        private partial struct ActivateMeleeAttackJob : IJobEntity
        {
            public EntityCommandBuffer.ParallelWriter ECB;
            [ReadOnly] public GlobalTimer GlobalTimer;
            [ReadOnly] public BlobAssetReference<AbilityConfigBlobTable> ConfigTableRef;

            // 查询：有 CAbilityInTryActivate + CAbilityType_MeleeAttack 的 Entity
            void Execute(Entity ability, [ChunkIndexInQuery] int sortKey,
                in CAbilityBaseInfo baseInfo,
                in CAbilityType_MeleeAttack _meleeTag,
                in CAbilityActivationParam param)
            {
                // 1. 从 BlobAsset 读取配置（零GC，Burst安全）
                ref var configs = ref ConfigTableRef.Value.Configs;
                int configIdx = FindConfigIndex(ref configs, baseInfo.Code);
                if (configIdx < 0) return;
                ref var config = ref configs[configIdx];

                // 2. 标记激活
                ECB.AddComponent<CAbilityActive>(sortKey, ability);
                ECB.RemoveComponent<CAbilityInTryActivate>(sortKey, ability);

                // 3. 触发 CD（添加 CD 命令组件，由 SAbilityCooldown 处理）
                if (config.CooldownFrames > 0)
                {
                    ECB.AddComponent(sortKey, ability, new CAbilityDoCooldown
                    {
                        StartFrame = GlobalTimer.Frame,
                        DurationFrames = config.CooldownFrames
                    });
                }

                // 4. 触发 Cost（添加 Cost 命令组件，由 SAbilityCost 处理）
                if (config.CostEffectCode > 0)
                {
                    ECB.AddComponent(sortKey, ability, new CAbilityDoCost
                    {
                        EffectCode = config.CostEffectCode
                    });
                }

                // 5. 发布激活事件（写入 Event Buffer，由 OOP Shell 订阅）
                ECB.AppendToBuffer(sortKey, baseInfo.Owner, new BAbilityActivatedEvent
                {
                    AbilityCode = baseInfo.Code,
                    Frame = GlobalTimer.Frame
                });

                GASLogger.Trace("[SMeleeAttackAbility] Ability {0} activated at frame {1}",
                    baseInfo.Code, GlobalTimer.Frame);
            }

            private static int FindConfigIndex(ref BlobArray<AbilityConfigBlob> configs, int code)
            {
                // BlobArray 支持二分查找（需要配置表按Code排序）
                int lo = 0, hi = configs.Length - 1;
                while (lo <= hi)
                {
                    int mid = (lo + hi) >> 1;
                    if (configs[mid].Code == code) return mid;
                    if (configs[mid].Code < code) lo = mid + 1;
                    else hi = mid - 1;
                }
                return -1;
            }
        }
    }
}
```

**设计合理性**：
- `[BurstCompile]` 全链路生效，能力激活逻辑跑在 native code 上
- `IJobEntity` 支持并行处理，1000个单位同时激活能力时性能线性扩展
- 通过 Tag Component 区分类型，ECS Archetype 自动分组，查询零开销
- 配置通过 BlobAsset 访问，零GC

### 3.3 ECS Core：属性计算 Burst 化

**设计信号**：Attribute 热路径应向纯数据计算与 Burst-friendly 结构收束。

```csharp
// ============================================================
// 文件: Assets/GAS/Runtime/System/Attribute/SAttributeCalculation.cs
// 职责: 纯血 ECS 属性重算，完全 Burst 编译
//       目标态参考：
//       当前版本调用 AttributeHelper.RecalculateCurrentValue（托管方法）
//       重构版本：所有计算在 Burst Job 内完成
// ============================================================
using Unity.Burst;
using Unity.Entities;
using Unity.Collections;

namespace GAS.Runtime
{
    [UpdateInGroup(typeof(SGAttribute))]
    [BurstCompile]
    public partial struct SAttributeCalculation : ISystem
    {
        [BurstCompile]
        public void OnCreate(ref SystemState state)
        {
            state.RequireForUpdate<CAttributeIsDirty>();
        }

        [BurstCompile]
        public void OnUpdate(ref SystemState state)
        {
            var ecb = new EntityCommandBuffer(Allocator.Temp);

            new RecalcAttributeJob
            {
                ECB = ecb.AsParallelWriter(),
                // 需要读取其他 ASC 的 Modifier Buffer（只读）
                ModifierBufferLookup = SystemAPI.GetBufferLookup<BEActiveModifier>(isReadOnly: true),
            }.ScheduleParallel();

            state.Dependency.Complete();
            ecb.Playback(state.EntityManager);
            ecb.Dispose();
        }

        [BurstCompile]
        private partial struct RecalcAttributeJob : IJobEntity
        {
            public EntityCommandBuffer.ParallelWriter ECB;
            [ReadOnly] public BufferLookup<BEActiveModifier> ModifierBufferLookup;

            void Execute(Entity asc, [ChunkIndexInQuery] int sortKey,
                in CAttributeIsDirty _dirty,
                DynamicBuffer<BEAttrSet> attrSets,
                DynamicBuffer<BEActiveModifier> modifiers)
            {
                // 遍历所有 AttrSet 中的 Dirty 属性
                for (int setIdx = 0; setIdx < attrSets.Length; setIdx++)
                {
                    var attrSet = attrSets[setIdx];
                    var attrs = attrSet.Attributes;

                    for (int attrIdx = 0; attrIdx < attrs.Length; attrIdx++)
                    {
                        var attr = attrs[attrIdx];
                        if (!attr.Dirty) continue;

                        // 重算：BaseValue + 所有 Add Modifier - 所有 Minus Modifier
                        float addSum = 0f, minusSum = 0f, multiplyProduct = 1f;
                        for (int modIdx = 0; modIdx < modifiers.Length; modIdx++)
                        {
                            var mod = modifiers[modIdx];
                            if (mod.AttrSetCode != attrSet.Code || mod.AttrCode != attr.Code)
                                continue;

                            switch (mod.Operation)
                            {
                                case GEOperation.Add:    addSum += mod.Magnitude; break;
                                case GEOperation.Minus:  minusSum += mod.Magnitude; break;
                                case GEOperation.Multiply: multiplyProduct *= mod.Magnitude; break;
                            }
                        }

                        float newCurrentValue = (attr.BaseValue + addSum - minusSum) * multiplyProduct;
                        newCurrentValue = math.clamp(newCurrentValue, attr.MinValue, attr.MaxValue);

                        attr.CurrentValue = newCurrentValue;
                        attr.Dirty = false;
                        attrs[attrIdx] = attr;
                    }

                    attrSet.Attributes = attrs;
                    attrSets[setIdx] = attrSet;
                }

                // 清除 Dirty 标记
                ECB.RemoveComponent<CAttributeIsDirty>(sortKey, asc);
            }
        }
    }
}
```

### 3.4 OOP Shell Layer：纯门面，零状态

**设计信号**：OOP Shell 只做边界适配，不作为 simulation 中间层或状态权威。

**重构方案**：`GASFacade` 只持有 `Entity`，通过 `CommandChannel` 提交命令，通过 `EventBus` 接收事件。

```csharp
// ============================================================
// 文件: Assets/GAS/Runtime/OOPShell/GASFacade.cs
// 职责: GAS 的 OOP 门面，面向业务层（UI、网络、AI）
//       设计准则：
//       1. 零运行时状态（不缓存任何ECS数据）
//       2. 零ECS类型泄漏（public API 无 Entity/IComponentData）
//       3. 只做两件事：提交命令 + 订阅事件
// ============================================================
using System;
using Unity.Entities;

namespace GAS.Runtime.Shell
{
    /// <summary>
    /// GAS 的 OOP 门面。
    /// 业务层（UI、网络、AI）通过此类与 GAS ECS Core 交互。
    /// 不持有任何运行时状态，不缓存任何 ECS 数据。
    /// </summary>
    public sealed class GASFacade : IDisposable
    {
        // 唯一持有的 ECS 类型：Entity（值类型，安全）
        private readonly Entity _ascEntity;
        private bool _disposed;

        // 事件订阅（ECS → OOP 的单向通道）
        private readonly GASEventBus _eventBus;

        public GASFacade(Entity ascEntity)
        {
            _ascEntity = ascEntity;
            _eventBus = new GASEventBus(ascEntity);
        }

        // ==================== 命令提交（OOP → ECS）====================

        /// <summary>
        /// 尝试激活能力。
        /// 内部：向 ECS CommandChannel 写入 CAbilityActivateCommand。
        /// 结果通过 OnAbilityActivated / OnAbilityActivateFailed 事件回调。
        /// </summary>
        public void TryActivateAbility(int abilityCode, AbilityParam param = default)
        {
            if (_disposed) return;
            GASCommandChannel.EnqueueActivateAbility(_ascEntity, abilityCode, param);
            GASLogger.Debug("[GASFacade] TryActivateAbility: asc={0}, code={1}",
                _ascEntity.Index, abilityCode);
        }

        /// <summary>尝试结束能力</summary>
        public void TryEndAbility(int abilityCode)
        {
            if (_disposed) return;
            GASCommandChannel.EnqueueEndAbility(_ascEntity, abilityCode);
        }

        /// <summary>尝试取消能力</summary>
        public void TryCancelAbility(int abilityCode)
        {
            if (_disposed) return;
            GASCommandChannel.EnqueueCancelAbility(_ascEntity, abilityCode);
        }

        /// <summary>施加 GameplayEffect</summary>
        public void ApplyEffect(int effectCode, GASFacade target)
        {
            if (_disposed || target == null) return;
            GASCommandChannel.EnqueueApplyEffect(_ascEntity, target._ascEntity, effectCode);
        }

        // ==================== 属性查询（只读，安全）====================

        /// <summary>
        /// 查询属性当前值。
        /// 注意：这是一次 EntityManager 读取，有轻微开销，
        /// 建议在 UI 更新时调用，不要在每帧 Update 中轮询。
        /// 推荐做法：订阅 OnAttributeChanged 事件，按需更新。
        /// </summary>
        public float GetAttributeCurrentValue(int attrSetCode, int attrCode)
        {
            if (_disposed) return 0f;
            return GASQuery.GetAttributeCurrentValue(_ascEntity, attrSetCode, attrCode);
        }

        /// <summary>查询是否拥有指定 Tag</summary>
        public bool HasTag(int tagCode)
        {
            if (_disposed) return false;
            return GASQuery.HasTag(_ascEntity, tagCode);
        }

        /// <summary>查询能力是否激活中</summary>
        public bool IsAbilityActive(int abilityCode)
        {
            if (_disposed) return false;
            return GASQuery.IsAbilityActive(_ascEntity, abilityCode);
        }

        // ==================== 事件订阅（ECS → OOP）====================

        /// <summary>订阅能力激活成功事件</summary>
        public void OnAbilityActivated(Action<int> callback) =>
            _eventBus.Subscribe<AbilityActivatedEvent>(e => callback(e.AbilityCode));

        /// <summary>订阅能力激活失败事件</summary>
        public void OnAbilityActivateFailed(Action<int, AbilityActivationResult> callback) =>
            _eventBus.Subscribe<AbilityActivateFailedEvent>(e => callback(e.AbilityCode, e.Reason));

        /// <summary>订阅属性变化事件（推荐UI使用）</summary>
        public void OnAttributeChanged(Action<int, int, float, float> callback) =>
            _eventBus.Subscribe<AttributeChangedEvent>(e =>
                callback(e.AttrSetCode, e.AttrCode, e.OldValue, e.NewValue));

        /// <summary>订阅 Tag 变化事件</summary>
        public void OnTagChanged(Action<int, bool> callback) =>
            _eventBus.Subscribe<TagChangedEvent>(e => callback(e.TagCode, e.Added));

        // ==================== 生命周期 ====================

        public void Dispose()
        {
            if (_disposed) return;
            _disposed = true;
            _eventBus.Dispose();
            GASCommandChannel.EnqueueDestroyAsc(_ascEntity);
            GASLogger.Info("[GASFacade] Disposed: asc={0}", _ascEntity.Index);
        }
    }
}
```

```csharp
// ============================================================
// 文件: Assets/GAS/Runtime/OOPShell/GASCommandChannel.cs
// 职责: OOP → ECS 的单向命令通道
//       使用 NativeQueue 替代全局静态 ECB，线程安全
//       ECS System 在每帧开始时消费命令队列
// ============================================================
using Unity.Entities;
using Unity.Collections;

namespace GAS.Runtime.Shell
{
    /// <summary>
    /// OOP → ECS 命令通道。
    /// 使用 NativeQueue 存储命令，ECS System 在帧开始时消费。
    /// 线程安全，支持从任意线程提交命令。
    /// </summary>
    public static class GASCommandChannel
    {
        // 使用 NativeQueue 替代全局 ECB，线程安全
        private static NativeQueue<GASCommand> _commandQueue;

        public static void Initialize()
        {
            _commandQueue = new NativeQueue<GASCommand>(Allocator.Persistent);
        }

        public static void Dispose()
        {
            if (_commandQueue.IsCreated) _commandQueue.Dispose();
        }

        public static void EnqueueActivateAbility(Entity asc, int abilityCode, AbilityParam param)
        {
            _commandQueue.Enqueue(new GASCommand
            {
                Type = GASCommandType.ActivateAbility,
                AscEntity = asc,
                IntParam1 = abilityCode,
                FloatParam1 = param.TargetX,
                FloatParam2 = param.TargetY,
                FloatParam3 = param.TargetZ,
            });
        }

        public static void EnqueueEndAbility(Entity asc, int abilityCode)
        {
            _commandQueue.Enqueue(new GASCommand
            {
                Type = GASCommandType.EndAbility,
                AscEntity = asc,
                IntParam1 = abilityCode,
            });
        }

        public static void EnqueueApplyEffect(Entity source, Entity target, int effectCode)
        {
            _commandQueue.Enqueue(new GASCommand
            {
```

```csharp
// ============================================================
// 文件: Assets/GAS/Runtime/System/Core/SConsumeCommands.cs
// 职责: 消费 GASCommandChannel 中的命令，转换为 ECS 组件操作
//       这是 OOP Shell 和 ECS Core 之间的唯一入口点
//       每帧在所有 GAS System 之前运行
// ============================================================
using Unity.Burst;
using Unity.Entities;

namespace GAS.Runtime
{
    [UpdateInGroup(typeof(SGLogic), OrderFirst = true)]
    public partial struct SConsumeCommands : ISystem
    {
        public void OnCreate(ref SystemState state) { }

        // 注意：此 System 不能 Burst 编译，因为需要访问 GASCommandChannel（托管静态类）
        // 但它只在每帧运行一次，且逻辑简单，性能影响可忽略
        public void OnUpdate(ref SystemState state)
        {
            var ecb = new EntityCommandBuffer(Unity.Collections.Allocator.Temp);

            while (GASCommandChannel.TryDequeue(out var cmd))
            {
                switch (cmd.Type)
                {
                    case GASCommandType.ActivateAbility:
                        ProcessActivateAbility(ref state, ref ecb, cmd);
                        break;
                    case GASCommandType.EndAbility:
                        ProcessEndAbility(ref state, ref ecb, cmd);
                        break;
                    case GASCommandType.CancelAbility:
                        ProcessCancelAbility(ref state, ref ecb, cmd);
                        break;
                    case GASCommandType.ApplyEffect:
                        ProcessApplyEffect(ref state, ref ecb, cmd);
                        break;
                    case GASCommandType.DestroyAsc:
                        ecb.DestroyEntity(cmd.AscEntity);
                        break;
                }
            }

            ecb.Playback(state.EntityManager);
            ecb.Dispose();
        }

        private void ProcessActivateAbility(ref SystemState state, ref EntityCommandBuffer ecb, GASCommand cmd)
        {
            // 在 ASC 的 BAbility buffer 中找到对应 Ability Entity
            if (!state.EntityManager.HasBuffer<BAbility>(cmd.AscEntity)) return;
            var abilities = state.EntityManager.GetBuffer<BAbility>(cmd.AscEntity);

            for (int i = 0; i < abilities.Length; i++)
            {
                var abilityEntity = abilities[i].Ability;
                if (!state.EntityManager.HasComponent<CAbilityBaseInfo>(abilityEntity)) continue;
                var info = state.EntityManager.GetComponentData<CAbilityBaseInfo>(abilityEntity);
                if (info.Code != cmd.IntParam1) continue;

                // 写入激活参数
                ecb.AddComponent(abilityEntity, new CAbilityActivationParam
                {
                    TargetX = cmd.FloatParam1,
                    TargetY = cmd.FloatParam2,
                    TargetZ = cmd.FloatParam3,
                });
                // 标记待激活
                ecb.AddComponent<CAbilityInTryActivate>(abilityEntity);
                break;
            }
        }

        private void ProcessEndAbility(ref SystemState state, ref EntityCommandBuffer ecb, GASCommand cmd)
        {
            if (!state.EntityManager.HasBuffer<BAbility>(cmd.AscEntity)) return;
            var abilities = state.EntityManager.GetBuffer<BAbility>(cmd.AscEntity);
            for (int i = 0; i < abilities.Length; i++)
            {
                var abilityEntity = abilities[i].Ability;
                var info = state.EntityManager.GetComponentData<CAbilityBaseInfo>(abilityEntity);
                if (info.Code == cmd.IntParam1)
                {
                    ecb.AddComponent<CAbilityInTryEnd>(abilityEntity);
                    break;
                }
            }
        }

        private void ProcessCancelAbility(ref SystemState state, ref EntityCommandBuffer ecb, GASCommand cmd)
        {
            if (!state.EntityManager.HasBuffer<BAbility>(cmd.AscEntity)) return;
            var abilities = state.EntityManager.GetBuffer<BAbility>(cmd.AscEntity);
            for (int i = 0; i < abilities.Length; i++)
            {
                var abilityEntity = abilities[i].Ability;
                var info = state.EntityManager.GetComponentData<CAbilityBaseInfo>(abilityEntity);
                if (info.Code == cmd.IntParam1)
                {
                    ecb.AddComponent<CAbilityInTryCancel>(abilityEntity);
                    break;
                }
            }
        }

        private void ProcessApplyEffect(ref SystemState state, ref EntityCommandBuffer ecb, GASCommand cmd)
        {
            // 创建 GE Apply 命令 Entity
            var cmdEntity = ecb.CreateEntity();
            ecb.AddComponent(cmdEntity, new CEffectApplyCommand
            {
                EffectCode = cmd.IntParam1,
                Source = cmd.AscEntity,
                Target = cmd.TargetEntity,
            });
        }
    }
}
```

```csharp
// ============================================================
// 文件: Assets/GAS/Runtime/General/GASLogger.cs
// 职责: GAS 专用结构化日志系统
//       设计目标：
//       1. ECS System 内部可用（包括 Burst 编译的 System）

//       4. 支持帧号/回合号自动附加，方便定位时序问题

using Unity.Burst;
using Unity.Collections;
using UnityEngine;

namespace GAS.Runtime
{
    public enum GASLogLevel : byte
    {
        Trace = 0,   // 最详细：每个组件变化
        Debug = 1,   // 调试：System 执行路径
        Info  = 2,   // 信息：重要状态变化（Ability激活、GE应用）
        Warn  = 3,   // 警告：非预期但可恢复的情况
        Error = 4,   // 错误：逻辑错误
        Off   = 5,   // 关闭
    }

    public enum GASLogModule : byte
    {
        All      = 0,
        Ability  = 1,
        Effect   = 2,
        Attribute= 3,
        Tag      = 4,
        Command  = 5,
        Data     = 6,
    }

    /// <summary>
    /// GAS 结构化日志系统。
    /// 
    /// 在 Burst 编译的 System 中使用 GASLogger.BurstLog()。
    /// 在普通 System/OOP 代码中使用 GASLogger.Info/Debug/Warn/Error()。
    /// 
    /// 生产环境：将 MinLevel 设为 Off，编译器会消除所有日志调用（零开销）。
    /// </summary>
    public static class GASLogger
    {
        // 运行时可调整
        public static GASLogLevel MinLevel = GASLogLevel.Info;
        public static GASLogModule EnabledModules = GASLogModule.All;

        // ==================== 普通日志（托管代码使用）====================

        public static void Trace(string format, params object[] args)
            => Log(GASLogLevel.Trace, GASLogModule.All, format, args);

        public static void Debug(string format, params object[] args)
            => Log(GASLogLevel.Debug, GASLogModule.All, format, args);

        public static void Info(string format, params object[] args)
            => Log(GASLogLevel.Info, GASLogModule.All, format, args);

        public static void Warn(string format, params object[] args)
            => Log(GASLogLevel.Warn, GASLogModule.All, format, args);

        public static void Error(string format, params object[] args)
            => Log(GASLogLevel.Error, GASLogModule.All, format, args);

        public static void Module(GASLogModule module, GASLogLevel level, string format, params object[] args)
            => Log(level, module, format, args);

        private static void Log(GASLogLevel level, GASLogModule module, string format, object[] args)
        {
            if (level < MinLevel) return;
            if (EnabledModules != GASLogModule.All && module != EnabledModules) return;

            // 自动附加帧号（方便定位时序问题）
            int frame = GASManager.IsInitialized ? GASManager.CurrentFrame : -1;
            string prefix = $"[GAS][F{frame}][{module}]";
            string message = args.Length > 0 ? string.Format(format, args) : format;
            string fullMessage = $"{prefix} {message}";

            switch (level)
            {
                case GASLogLevel.Trace:
                case GASLogLevel.Debug: UnityEngine.Debug.Log(fullMessage); break;
                case GASLogLevel.Info:  UnityEngine.Debug.Log(fullMessage); break;
                case GASLogLevel.Warn:  UnityEngine.Debug.LogWarning(fullMessage); break;
                case GASLogLevel.Error: UnityEngine.Debug.LogError(fullMessage); break;
            }
        }

        // ==================== Burst 兼容日志（ECS Job 内使用）====================
        // Burst 中不能用 string.Format，使用 FixedString

        [BurstDiscard] // 在 Burst 中此方法被丢弃，不产生编译错误
        public static void BurstLog(GASLogLevel level, in FixedString128Bytes message)
        {
            if (level < MinLevel) return;
            switch (level)
            {
                case GASLogLevel.Warn:  UnityEngine.Debug.LogWarning(message.ToString()); break;
                case GASLogLevel.Error: UnityEngine.Debug.LogError(message.ToString()); break;
                default:                UnityEngine.Debug.Log(message.ToString()); break;
            }
        }
    }
}
```

## 四、目标态收益信号

| 维度 | 目标态信号 |
|------|------------|
| **Burst 覆盖率** | Gameplay 热路径尽量向 Burst-friendly / job-friendly 收束，表现层和工具层保留 managed 边界。 |
| **OOP层职责** | 纯门面，零 gameplay 状态，只提交命令、读取事实和表现投影。 |
| **配置数据访问** | Definition 数据最终进入 Blob / generated builder / registry 等稳定 carrier。 |
| **ECB管理** | 结构变更由明确 System / ECB / request 管线处理，不使用全局便利入口。 |
| **System注册** | 调度顺序集中表达并可测试。当前实现倾向显式 schedule contract。 |
| **Ability类型扩展** | 新增配置 Schema、组件和 System，避免恢复托管 Ability 执行对象。 |
| **日志调试** | 结构化事实流，模块、帧号、事件类型可追踪。 |
| **线程安全** | 命令和事件通过 ECS 数据流表达，减少跨层共享可变状态。 |

## 五、可吸收路线信号

从业务角度，这套架构不能再按旧主链迁移步骤执行。当前可吸收的是分阶段原则：

1. 先把结构化事实流和 debug/replay sink 建好，而不是散落 `Debug.Log`。
2. 再把 Luban / registry / prototype / Blob 的 definition authority 压实。
3. Ability 行为继续向配置 Schema + ECS component/system 迁移，不恢复托管 Ability 执行对象。
4. OOP 接入层只保留 Facade / Binding，不重新承担 runtime state 或 Controller 职责。

```csharp
// ============================================================
// 文件: Assets/GAS/Runtime/OOPShell/GASEventBus.cs
// 职责: ECS → OOP 的单向事件总线
//       ECS System 将事件写入 DynamicBuffer<BXxxEvent>，
//       GASEventBus 在每帧末尾（LateUpdate）消费并分发给订阅者
//       这样 ECS 和 OOP 之间完全解耦，ECS 不依赖任何 OOP 类型
// ============================================================
using System;
using System.Collections.Generic;
using Unity.Entities;
using UnityEngine;

namespace GAS.Runtime.Shell
{
    public sealed class GASEventBus : IDisposable
    {
        private readonly Entity _ascEntity;
        private readonly Dictionary<Type, List<Delegate>> _subscribers = new();
        private bool _disposed;

        public GASEventBus(Entity ascEntity)
        {
            _ascEntity = ascEntity;
            // 注册到全局 EventBus 调度器，每帧 LateUpdate 时消费
            GASEventDispatcher.Register(this);
        }

        public void Subscribe<T>(Action<T> callback) where T : struct
        {
            var type = typeof(T);
            if (!_subscribers.TryGetValue(type, out var list))
                _subscribers[type] = list = new List<Delegate>();
            list.Add(callback);
        }

        /// <summary>
        /// 由 GASEventDispatcher 在 LateUpdate 调用，
        /// 消费 ECS Buffer 中的事件并分发给订阅者。
        /// </summary>
        internal void Flush(EntityManager em)
        {
            if (_disposed) return;

            // 消费 AbilityActivatedEvent
            FlushBuffer<BAbilityActivatedEvent, AbilityActivatedEvent>(em,
                b => new AbilityActivatedEvent { AbilityCode = b.AbilityCode, Frame = b.Frame });

            // 消费 AttributeChangedEvent
            FlushBuffer<BAttributeChangedEvent, AttributeChangedEvent>(em,
                b => new AttributeChangedEvent
                {
                    AttrSetCode = b.AttrSetCode,
                    AttrCode = b.AttrCode,
                    OldValue = b.OldValue,
                    NewValue = b.NewValue
                });

            // 消费 TagChangedEvent
            FlushBuffer<BTagChangedEvent, TagChangedEvent>(em,
                b => new TagChangedEvent { TagCode = b.TagCode, Added = b.Added });
        }

        private void FlushBuffer<TBuffer, TEvent>(EntityManager em, Func<TBuffer, TEvent> converter)
            where TBuffer : unmanaged, IBufferElementData
            where TEvent : struct
        {
            if (!em.HasBuffer<TBuffer>(_ascEntity)) return;
            var buffer = em.GetBuffer<TBuffer>(_ascEntity);
            if (buffer.Length == 0) return;

            if (!_subscribers.TryGetValue(typeof(TEvent), out var callbacks)) 
            {
                buffer.Clear();
                return;
            }

            for (int i = 0; i < buffer.Length; i++)
            {
                var evt = converter(buffer[i]);
                foreach (var cb in callbacks)
                    ((Action<TEvent>)cb)?.Invoke(evt);
            }
            buffer.Clear();
        }

        public void Dispose()
        {
            if (_disposed) return;
            _disposed = true;
            GASEventDispatcher.Unregister(this);
            _subscribers.Clear();
        }
    }

    // 轻量级 MonoBehaviour，挂载在 GASManager GameObject 上，
    // 负责在 LateUpdate 驱动所有 EventBus 的 Flush
    public class GASEventDispatcher : MonoBehaviour
    {
        private static readonly List<GASEventBus> _buses = new();

        public static void Register(GASEventBus bus) => _buses.Add(bus);
        public static void Unregister(GASEventBus bus) => _buses.Remove(bus);

        private void LateUpdate()
        {
            var em = GASManager.EntityManager;
            foreach (var bus in _buses)
                bus.Flush(em);
        }
    }
}
```

| 日志定位问题 | 无结构化，靠猜 | 帧号+模块过滤，秒级定位 | 质变 |

---

这套重构方案的核心思想是：**ECS 是 GamePlay 的底层物理引擎，OOP 是面向业务的人机界面**。两者之间通过 `CommandChannel`（OOP→ECS）和 `EventBus`（ECS→OOP）单向通信，彻底消除双向依赖，让 ECS 的 Burst/Job 优势得到完整释放。
