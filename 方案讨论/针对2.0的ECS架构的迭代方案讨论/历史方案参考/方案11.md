# EX-GAS 2.0 架构深度分析与重构方案

## 瘦身口径

> 已移除基于 2.0 旧状态的开头问题诊断和明显过时的旧主链对比；保留原始方案中仍可借鉴的架构分层、代码块、图示和实施思路。当前分支事实以 `../00-当前架构事实/README.md` 为准；当前任务路线以 `../02-主线任务树/README.md` 为准；目标态吸收关系以 `../01-目标态架构共识/README.md` 及各 Spec 的 `历史方案定位` 为准。

## 保留的目标态信号

- OOP 层定位为边界适配器，不能反向成为 ECS simulation 的状态源。
- Ability 行为应向数据化、事件化和专用 System 收束。
- Tag / Attribute / GE 配置应逐步转向 Burst-friendly 的连续数据和 definition carrier。
- Luban 配置链路可以继续向 BlobAsset / generated builder 演进，但必须在当前 registry / definition contract 稳定后推进。
- 结构化日志和事件 Buffer 有价值，但当前实现应优先复用 `CGameplayEventBus / BPresentationEvent / BDebugReplayEvent` 的分层事实流。

## 原始重构架构设计

### 3.1 Ability 行为数据化目标态参考

**核心思路**：用 `IAbilityBehavior` 接口 + 注册表替代 OOP 继承，GamePlay 核心逻辑（CD/Cost/Tag）完全 Burst 化，自定义逻辑通过 ECS 事件 Buffer 传递给表现层。

```csharp
// ============================================================
// [重构] 技能行为注册表 — 历史替代方向参考
// 文件: Runtime/Ability/AbilityBehaviorRegistry.cs
// ============================================================

/// <summary>
/// 技能行为接口 — 纯 C# 接口，不依赖 ECS 类型
/// 实现者只关心"发生了什么"，不关心"怎么存储"
/// </summary>
public interface IAbilityBehavior
{
    /// <summary>技能激活时的自定义逻辑（表现层：动画、特效触发）</summary>
    void OnActivate(in AbilityActivateContext ctx);
    /// <summary>技能每帧 Tick（表现层：持续特效更新）</summary>
    void OnTick(in AbilityTickContext ctx);
    /// <summary>技能结束</summary>
    void OnEnd(in AbilityEndContext ctx);
    /// <summary>技能取消</summary>
    void OnCancel(in AbilityEndContext ctx);
}

/// <summary>
/// 技能激活上下文 — 只暴露业务需要的信息，不暴露 ECS 类型
/// </summary>
public readonly struct AbilityActivateContext
{
    public readonly int AbilityCode;
    public readonly int OwnerInstanceId;   // 对应 GameObject.GetInstanceID()
    public readonly int Level;
    public readonly XParam Param;
    public readonly int CurrentFrame;
}

/// <summary>
/// 技能行为注册表 — 静态字典，启动时注册，运行时只读
/// </summary>
public static class AbilityBehaviorRegistry
{
    private static readonly Dictionary<int, IAbilityBehavior> _behaviors = new();

    public static void Register(int abilityCode, IAbilityBehavior behavior)
        => _behaviors[abilityCode] = behavior;

    public static bool TryGet(int abilityCode, out IAbilityBehavior behavior)
        => _behaviors.TryGetValue(abilityCode, out behavior);
}
```

```csharp
// ============================================================
// [重构] ECS 技能激活系统 — 完全 Burst 化的 GamePlay 核心
// 文件: Runtime/System/Ability/STryActivateAbility.cs
// ============================================================

[UpdateInGroup(typeof(SGAbility))]
[BurstCompile]  // ← 现在可以 Burst 了！
public partial struct STryActivateAbility : ISystem
{
    [BurstCompile]
    public void OnCreate(ref SystemState state)
    {
        state.RequireForUpdate<CAbilityInTryActivate>();
    }

    [BurstCompile]  // ← 核心 GamePlay 逻辑全部 Burst
    public void OnUpdate(ref SystemState state)
    {
        var ecb = new EntityCommandBuffer(Allocator.Temp);
        var globalTimer = SystemAPI.GetSingleton<GlobalTimer>();

        foreach (var (_, basicInfo, ability) in SystemAPI
            .Query<RefRO<CAbilityInTryActivate>, RefRO<CAbilityBaseInfo>>()
            .WithEntityAccess())
        {
            var result = AbilityUtil.CanActivateAbility(ability, ref state);
            if (result == AbilityActivationResult.Success)
            {
                // 1. 添加激活标记（纯 ECS，Burst 安全）
                ecb.AddComponent<CAbilityActive>(ability);

                // 2. 添加 ActivationOwnedTags（纯 ECS）
                if (state.EntityManager.HasComponent<CAbilityActivationOwnedTags>(ability))
                {
                    var ownedTags = state.EntityManager
                        .GetComponentData<CAbilityActivationOwnedTags>(ability);
                    TagHelper.AddTemporaryTagsTo(basicInfo.ValueRO.Owner, ability,
                        ownedTags.Tags, ref ecb);
                }

                // 3. 写入事件 Buffer（不调用 OOP，只写数据）
                ecb.AppendToBuffer(basicInfo.ValueRO.Owner, new BAbilityEvent
                {
                    EventType = AbilityEventType.Activated,
                    AbilityCode = basicInfo.ValueRO.Code,
                    Frame = globalTimer.Frame
                });

                // 4. 取消被 CancelAbilityWithTags 标记的其他技能
                AbilityUtil.CancelAbilitiesWithTags(ability, ref state, ref ecb);
            }

            // 5. 写入激活结果事件（供 OOP 层订阅）
            ecb.AppendToBuffer(basicInfo.ValueRO.Owner, new BAbilityActivateResultEvent
            {
                AbilityCode = basicInfo.ValueRO.Code,
                Result = result
            });

            ecb.RemoveComponent<CAbilityInTryActivate>(ability);
        }

        ecb.Playback(state.EntityManager);
        ecb.Dispose();
    }
}
```

```csharp
// ============================================================
// [重构] 表现层系统 — 消费事件 Buffer，调用 OOP 行为
// 文件: Runtime/System/Presentation/SAbilityEventDispatcher.cs
// ============================================================

/// <summary>
/// 表现层系统：消费 BAbilityEvent，调用注册的 IAbilityBehavior
/// 运行在 SimulationSystemGroup（非 FixedStep），不影响 GamePlay 确定性
/// </summary>
[UpdateInGroup(typeof(SysGrpDisplay))]
public partial class SAbilityEventDispatcher : SystemBase  // Managed System，允许访问 OOP
{
    protected override void OnUpdate()
    {
        var em = EntityManager;

        foreach (var (events, basicData, asc) in SystemAPI
            .Query<DynamicBuffer<BAbilityEvent>, RefRO<CAscBasicData>>()
            .WithEntityAccess())
        {
            if (events.Length == 0) continue;

            var ownerInstanceId = em.HasComponent<CGameObjectRef>(asc)
                ? em.GetComponentData<CGameObjectRef>(asc).InstanceId
                : 0;

            for (int i = 0; i < events.Length; i++)
            {
                var evt = events[i];
                if (!AbilityBehaviorRegistry.TryGet(evt.AbilityCode, out var behavior))
                    continue;

                switch (evt.EventType)
                {
                    case AbilityEventType.Activated:
                        behavior.OnActivate(new AbilityActivateContext
                        {
                            AbilityCode = evt.AbilityCode,
                            OwnerInstanceId = ownerInstanceId,
                            CurrentFrame = evt.Frame
                        });
                        break;
                    case AbilityEventType.Ended:
                        behavior.OnEnd(new AbilityEndContext
                        {
                            AbilityCode = evt.AbilityCode,
                            OwnerInstanceId = ownerInstanceId
                        });
                        break;
                }
            }

            // 消费完毕，清空 Buffer
            events.Clear();
        }
    }
}
```

### 3.2 OOP 层重新定位：纯粹的边界适配器

```csharp
// ============================================================
// [重构] AbilitySystemFacade — OOP 层只作为命令发送器
// 文件: Runtime/Facade/AbilitySystemFacade.cs
// ============================================================

/// <summary>
/// OOP 门面层：供 MonoBehaviour、UI、网络模块使用
/// 设计原则：
///   1. 只持有 Entity 引用（不持有 Controller 对象）
///   2. 只向 ECS 发送命令（单向写入）
///   3. 通过订阅 BAbilityActivateResultEvent 获取结果（事件驱动）
///   4. 不在内部维护任何与 ECS 并行的 OOP 状态
/// </summary>
public sealed class AbilitySystemFacade
{
    private readonly Entity _ascEntity;
    private static EntityManager Em => GASManager.EntityManager;

    // 事件订阅（OOP 层的唯一"读取"方式）
    public event Action<int, AbilityActivationResult> OnAbilityActivateResult;
    public event Action<int, float, float> OnAttributeChanged; // attrCode, oldVal, newVal

    public AbilitySystemFacade(Entity ascEntity)
    {
        _ascEntity = ascEntity;
    }

    // ── 命令发送（写入 ECS，不读取）──

    /// <summary>请求激活技能（下一帧由 STryActivateAbility 处理）</summary>
    public void TryActivateAbility(int abilityCode, XParam param = null)
    {
        var buffer = Em.GetBuffer<BAbility>(_ascEntity);
        for (int i = 0; i < buffer.Length; i++)
        {
            var abi = Em.GetComponentData<CAbilityBaseInfo>(buffer[i].Ability);
            if (abi.Code != abilityCode) continue;

            // 设置参数（通过 unmanaged component，避免 Managed Component）
            if (param != null)
                Em.SetComponentData(buffer[i].Ability,
                    new CAbilityParam { ParamHandle = XParamRegistry.Register(param) });

            Em.AddComponent<CAbilityInTryActivate>(buffer[i].Ability);
            break;
        }
    }

    /// <summary>请求结束技能</summary>
    public void TryEndAbility(int abilityCode)
        => SetAbilityCommandFlag<CAbilityInTryEnd>(abilityCode);

    /// <summary>请求取消技能</summary>
    public void TryCancelAbility(int abilityCode)
        => SetAbilityCommandFlag<CAbilityInTryCancel>(abilityCode);

    // ── 状态查询（只读，不缓存）──

    public bool IsAbilityActive(int abilityCode)
    {
        var buffer = Em.GetBuffer<BAbility>(_ascEntity);
        for (int i = 0; i < buffer.Length; i++)
        {
            var abi = Em.GetComponentData<CAbilityBaseInfo>(buffer[i].Ability);
            if (abi.Code == abilityCode)
                return Em.HasComponent<CAbilityActive>(buffer[i].Ability);
        }
        return false;
    }

    public float GetAttrCurrentValue(int attrSetCode, int attrCode)
        => AttributeHelper.GetCurrentValue(_ascEntity, attrSetCode, attrCode);

    // ── 内部帮助 ──

    private void SetAbilityCommandFlag<T>(int abilityCode) where T : unmanaged, IComponentData
    {
        var buffer = Em.GetBuffer<BAbility>(_ascEntity);
        for (int i = 0; i < buffer.Length; i++)
        {
            var abi = Em.GetComponentData<CAbilityBaseInfo>(buffer[i].Ability);
            if (abi.Code != abilityCode) continue;
            if (!Em.HasComponent<T>(buffer[i].Ability))
                Em.AddComponent<T>(buffer[i].Ability);
            break;
        }
    }

    // ── 事件消费（由 SAbilityEventDispatcher 调用）──
    internal void DispatchActivateResult(int abilityCode, AbilityActivationResult result)
        => OnAbilityActivateResult?.Invoke(abilityCode, result);
}
```

```csharp
/// <summary>

    public bool HasTag(int tag)

    }
}

    public FixedList32Bytes<int> Any;
    public FixedList32Bytes<int> None;
```

### 3.4 Luban 配置链路：生成 BlobAsset

```csharp
// ============================================================
// [重构] Luban 配置 → BlobAsset 转换器
// 文件: Runtime/Data/GASBlobAssetBuilder.cs
// ============================================================

/// <summary>
/// GE 配置的 BlobAsset 结构
/// 零拷贝，Burst 可访问，存储在非托管内存
/// </summary>
public struct GameplayEffectConfigBlob
{
    public int ConfigId;
    public BlobArray<EffectModifierBlob> Modifiers;
    public BlobArray<int> GrantedTags;
    public BlobArray<int> ApplicationRequiredTags;
    public int Duration;          // -1 = Infinite
    public int Period;
    public TimeUnit TimeUnit;
    public EffectStackType StackType;
    public int StackLimit;
}

public struct EffectModifierBlob
{
    public int AttrSetCode;
    public int AttrCode;
    public GEOperation Operation;
    public float Magnitude;
    public int MmcCode;           // 0 = 无 MMC
}

/// <summary>
/// 技能配置的 BlobAsset
/// </summary>
public struct AbilityConfigBlob
{
    public int Code;
    public int Level;
    public BlobPtr<GameplayEffectConfigBlob> CooldownGE;
    public BlobPtr<GameplayEffectConfigBlob> CostGE;
    public BlobArray<int> AssetTags;
    public BlobArray<int> ActivationOwnedTags;
    public BlobArray<int> ActivationRequiredAll;
    public BlobArray<int> ActivationBlockedNone;
}

/// <summary>
/// 启动时将 Luban 生成的 JSON 数据转换为 BlobAsset
/// 只执行一次，之后所有 System 通过 BlobAssetReference 零拷贝访问
/// </summary>
public static class GASBlobAssetBuilder
{
    private static readonly Dictionary<int, BlobAssetReference<GameplayEffectConfigBlob>>
        _geBlobs = new();
    private static readonly Dictionary<int, BlobAssetReference<AbilityConfigBlob>>
        _abilityBlobs = new();

    public static void BuildAll()
    {
        BuildGameplayEffectBlobs();
        BuildAbilityBlobs();
    }

    private static void BuildGameplayEffectBlobs()
    {
        // XLuban.TbGameplayEffect 是 Luban 生成的表
        foreach (var cfg in XLuban.TbGameplayEffect.DataList)
        {
            var builder = new BlobBuilder(Allocator.Temp);
            ref var root = ref builder.ConstructRoot<GameplayEffectConfigBlob>();

            root.ConfigId = cfg.Id;
            root.Duration = cfg.Duration;
            root.Period = cfg.Period;
            root.TimeUnit = (TimeUnit)cfg.TimeUnit;
            root.StackType = (EffectStackType)cfg.StackType;
            root.StackLimit = cfg.StackLimit;

            // 构建 Modifiers 数组
            var modifiers = builder.Allocate(ref root.Modifiers, cfg.Modifiers.Count);
            for (int i = 0; i < cfg.Modifiers.Count; i++)
            {
                modifiers[i] = new EffectModifierBlob
                {
                    AttrSetCode = cfg.Modifiers[i].AttrSetCode,
                    AttrCode = cfg.Modifiers[i].AttrCode,
                    Operation = (GEOperation)cfg.Modifiers[i].Operation,
                    Magnitude = cfg.Modifiers[i].Magnitude,
                    MmcCode = cfg.Modifiers[i].MmcCode
                };
            }

            // 构建 GrantedTags 数组
            var grantedTags = builder.Allocate(ref root.GrantedTags, cfg.GrantedTags.Count);
            for (int i = 0; i < cfg.GrantedTags.Count; i++)
                grantedTags[i] = cfg.GrantedTags[i];

            var blobRef = builder.CreateBlobAssetReference<GameplayEffectConfigBlob>(
                Allocator.Persistent);
            builder.Dispose();

            _geBlobs[cfg.Id] = blobRef;
        }
    }

    public static BlobAssetReference<GameplayEffectConfigBlob> GetGEBlob(int configId)
        => _geBlobs.GetValueOrDefault(configId);

    public static BlobAssetReference<AbilityConfigBlob> GetAbilityBlob(int abilityCode)
        => _abilityBlobs.GetValueOrDefault(abilityCode);

    public static void Dispose()
    {
        foreach (var blob in _geBlobs.Values) blob.Dispose();
        foreach (var blob in _abilityBlobs.Values) blob.Dispose();
        _geBlobs.Clear();
        _abilityBlobs.Clear();
    }
}
```

```csharp
// ============================================================
// [重构] GE Entity 创建 — 从 BlobAsset 构建，Burst 可访问
// 文件: Runtime/Effect/GameplayEffectHelper.cs
// ============================================================

/// <summary>
/// GE Entity 持有 BlobAsset 引用，System 直接读取，零拷贝
/// </summary>
public struct CEffectConfigRef : IComponentData
{
    public BlobAssetReference<GameplayEffectConfigBlob> Config;
}

public static class GameplayEffectHelper
{
    /// <summary>
    /// 从 BlobAsset 创建 GE Entity（替代原来的 ComponentConfig 逐个 AddComponent）
    /// </summary>
    public static Entity CreateFromBlob(int configId, EntityManager em)
    {
        var blobRef = GASBlobAssetBuilder.GetGEBlob(configId);
        if (!blobRef.IsCreated)
        {
            Debug.LogError($"[GAS] GE Config {configId} BlobAsset not found!");
            return Entity.Null;
        }

        ref var cfg = ref blobRef.Value;

        // 使用预定义 Archetype，避免运行时动态 AddComponent
        var archetype = GetOrCreateGEArchetype(cfg, em);
        var entity = em.CreateEntity(archetype);

        em.SetComponentData(entity, new CEffectConfigRef { Config = blobRef });
        em.SetComponentData(entity, new CEffectBasicInfo { ConfigId = cfg.ConfigId });

        if (cfg.Duration != 0)
            em.SetComponentData(entity, new CDuration
            {
                duration = cfg.Duration,
                timeUnit = cfg.TimeUnit
            });

        if (cfg.Period > 0)
            em.SetComponentData(entity, new CPeriod { Period = cfg.Period });

        if (cfg.StackType != EffectStackType.None)
            em.SetComponentData(entity, new CStacking
            {
                StackType = cfg.StackType,
                LimitCount = cfg.StackLimit
            });

        return entity;
    }

    // Archetype 缓存，避免重复创建
    private static readonly Dictionary<int, EntityArchetype> _archetypeCache = new();

    private static EntityArchetype GetOrCreateGEArchetype(
        in GameplayEffectConfigBlob cfg, EntityManager em)
    {
        if (_archetypeCache.TryGetValue(cfg.ConfigId, out var cached))
            return cached;

        // 根据配置特征决定 Archetype 组成
        var types = new List<ComponentType>
        {
            typeof(CEffectConfigRef),
            typeof(CEffectBasicInfo),
            typeof(CEffectApplyRequest)
        };

        if (cfg.Duration != 0) types.Add(typeof(CDuration));
        if (cfg.Period > 0) types.Add(typeof(CPeriod));
        if (cfg.StackType != EffectStackType.None) types.Add(typeof(CStacking));
        if (cfg.GrantedTags.Length > 0) types.Add(typeof(CEffectGrantedTagsRef));

        var archetype = em.CreateArchetype(types.ToArray());
        _archetypeCache[cfg.ConfigId] = archetype;
        return archetype;
    }
}
```

```csharp
{
    // 结构化日志输出，方便接入 GASWatcher 或外部日志系统
    private static readonly StringBuilder _sb = new StringBuilder(4096);

    protected override void OnUpdate()
    {
        var logCollector = SystemAPI.GetSingleton<CGASLogCollector>();
        if (!logCollector.Enabled) return;

        // 消费全局日志 Buffer
        foreach (var (events, asc) in SystemAPI
            .Query<DynamicBuffer<BGASLogEvent>>()
            .WithEntityAccess())
        {
            if (events.Length == 0) continue;

            for (int i = 0; i < events.Length; i++)
            {
                var evt = events[i];
                FormatAndOutput(evt, asc);
            }
            events.Clear();
        }
    }

    private void FormatAndOutput(in BGASLogEvent evt, Entity asc)
    {
        _sb.Clear();
        _sb.Append($"[GAS][F{evt.Frame}][{EntityHelper.GetEntityName(asc)}] ");

        switch (evt.EventType)
        {
            case GASLogEventType.AbilityActivated:
                _sb.Append($"Ability({evt.SubjectCode}) ACTIVATED");
                break;
            case GASLogEventType.AbilityActivateFailed:
                _sb.Append($"Ability({evt.SubjectCode}) FAILED: {evt.FailReason}");
                break;
            case GASLogEventType.AttributeChanged:
                _sb.Append($"Attr({evt.SubjectCode}) {evt.ValueBefore:F2} → {evt.ValueAfter:F2}");
                break;
            case GASLogEventType.GEApplied:
                _sb.Append($"GE({evt.SubjectCode}) Applied: " +
                           $"{EntityHelper.GetEntityName(evt.SourceEntity)} → " +
                           $"{EntityHelper.GetEntityName(evt.TargetEntity)}");
                break;
            case GASLogEventType.TagAdded:
                _sb.Append($"Tag({evt.SubjectCode}) ADDED");
                break;
        }

        Debug.Log(_sb.ToString());
    }
}
```

## 四、目标态收益信号

| 维度 | 目标态信号 |
|---|---|
| **Burst 覆盖率** | Gameplay 热路径尽量向 Burst-friendly / job-friendly 收束，表现层和工具层保留 managed 边界。 |
| **OOP 层定位** | OOP 只作边界适配器，单向发命令并读取事实投影。 |
| **技能逻辑** | Ability 行为通过数据、事件和专用 System 表达。 |
| **Tag 存储** | Tag / Requirement 数据最终应适配连续数据、mask 或 BlobArray 等 Burst-friendly 表达。 |
| **配置访问** | 启动或生成阶段构建稳定 definition carrier，运行时减少托管配置反查。 |
| **Entity 反查** | Simulation 不依赖 GameObject / OOP 对象反查；表现层绑定留在 presentation boundary。 |
| **调试能力** | ECS fact stream / log buffer / replay sink 支撑运行时可查。 |
| **GC 压力** | 命令、事件、临时状态通过 ECS 数据流表达，减少跨层托管分配。 |

## 五、关于 Luban 配置链路的进一步解放

当前 Luban 只生成了 JSON + C# 常量。重构后可以让 Luban 直接生成 **BlobAsset 构建代码**：

```
Excel (#exgas.gameplayEffect.xlsx)
    ↓ Luban gen
JSON (exgas_tbgameplayeffect.json)  +  GEBlobBuilder.gen.cs  ← 新增
    ↓ 启动时执行 GEBlobBuilder.gen.cs
BlobAssetReference<GameplayEffectConfigBlob>  ← 零拷贝，Burst 可访问
    ↓ 存入 CEffectConfigRef Component
ECS System 直接读取，无 GC，无反射
```

Luban 的 `custom_template` 功能可以生成任意代码，完全可以输出 `BlobBuilder` 填充代码，让配置链路从 Excel 到 BlobAsset 完全自动化，这才是 Luban 在 ECS 架构下真正的潜力所在。
