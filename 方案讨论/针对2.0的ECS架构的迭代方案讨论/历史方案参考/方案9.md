## 二、重构架构设计：ECS-First GAS

### 核心原则

```
┌─────────────────────────────────────────────────────────┐
│  业务层 (UI / 网络 / 输入)  ← OOP 外壳（唯一出口）       │
├─────────────────────────────────────────────────────────┤
│  OOP Bridge Layer                                        │
│  AbilitySystemFacade / GEFacade                          │
│  职责：ECS事件读取 → OOP事件分发，OOP命令 → ECS命令写入  │
├─────────────────────────────────────────────────────────┤
│  ECS GamePlay Core（纯血 ECS，全 Burst）                 │
│  Tag / Attribute / Effect / Ability / Cue Systems        │
├─────────────────────────────────────────────────────────┤
│  Luban Data Layer                                        │
│  Excel → Luban → BlobAsset（烘焙期完成，零运行时解析）   │
└─────────────────────────────────────────────────────────┘
```

### 3.1 Luban 配置直接映射为 BlobAsset（配置链路升级）


**重构方案**：Luban 生成的数据在 Baking 阶段转换为 `BlobAsset`，运行时零解析。

```csharp
// ============================================================
// [新] GE 配置的 BlobAsset 结构（纯非托管，Burst 友好）
// 文件：Assets/GAS/Runtime/Effect/Data/GEConfigBlob.cs
// ============================================================
using Unity.Entities;
using Unity.Collections;

namespace GAS.Runtime
{
    // Modifier 的 Blob 表示
    public struct BlobModifier
    {
        public int AttrSetCode;
        public int AttrCode;
        public GEOperation Operation;
        public float Magnitude;
        public int MmcCode; // 0 = 无 MMC，>0 = 查 MMC 表

    public struct GEConfigBlob

        public BlobArray<int> OngoingRequiredTags;
```

```csharp
// ============================================================
// [新] Luban → BlobAsset Baker（编辑器/Baking 期执行）
// 文件：Assets/GAS/Runtime/Effect/Data/GEConfigBaker.cs
// ============================================================
// 这个 Baker 在进入 PlayMode 或 Build 时自动执行，
// 将 XLuban 加载的 GE 配置表烘焙为 BlobAsset，
// 运行时完全不需要 JSON 解析。
using Unity.Entities;
using Unity.Collections;
using UnityEngine;

namespace GAS.Runtime
{
    // 挂在场景中的 Authoring GameObject 上
    public class GEConfigLibraryAuthoring : MonoBehaviour { }

    public class GEConfigLibraryBaker : Baker<GEConfigLibraryAuthoring>
    {
        public override void Bake(GEConfigLibraryAuthoring authoring)
        {
            // 从 Luban 加载所有 GE 配置（只在 Baking 期执行一次）
            var allConfigs = XLuban.GetAllGEConfigs(); // Luban 生成的 API

            var builder = new BlobBuilder(Allocator.Temp);
            ref var mapRoot = ref builder.ConstructRoot<GEConfigBlobMap>();

            int count = allConfigs.Count;
            var keysArr = builder.Allocate(ref mapRoot.Keys, count);
            var valsArr = builder.Allocate(ref mapRoot.Values, count);

            for (int i = 0; i < count; i++)
            {
                var cfg = allConfigs[i];
                keysArr[i] = cfg.Id;

                // 为每个 GE 配置构建独立的 BlobAsset
                var geBuilder = new BlobBuilder(Allocator.Temp);
                ref var geBlob = ref geBuilder.ConstructRoot<GEConfigBlob>();

                geBlob.ConfigId = cfg.Id;
                geBlob.Name = cfg.Name;
                geBlob.DurationType = cfg.DurationType;
                geBlob.Duration = cfg.Duration;
                geBlob.Period = cfg.Period;
                geBlob.TimeUnit = cfg.TimeUnit;

                // 填充 Tag 数组
                FillBlobArray(ref geBuilder, ref geBlob.AssetTags, cfg.AssetTags);
                FillBlobArray(ref geBuilder, ref geBlob.GrantedTags, cfg.GrantedTags);
                FillBlobArray(ref geBuilder, ref geBlob.ApplicationRequiredTags, cfg.ApplicationRequiredTags);
                FillBlobArray(ref geBuilder, ref geBlob.OngoingRequiredTags, cfg.OngoingRequiredTags);

                // 填充 Modifier 数组
                var modArr = geBuilder.Allocate(ref geBlob.Modifiers, cfg.Modifiers.Count);
                for (int m = 0; m < cfg.Modifiers.Count; m++)
                {
                    modArr[m] = new BlobModifier
                    {
                        AttrSetCode = cfg.Modifiers[m].AttrSetCode,
                        AttrCode = cfg.Modifiers[m].AttrCode,
                        Operation = cfg.Modifiers[m].Operation,
                        Magnitude = cfg.Modifiers[m].Magnitude,
                        MmcCode = cfg.Modifiers[m].MmcCode
                    };
                }

                valsArr[i] = geBuilder.CreateBlobAssetReference<GEConfigBlob>(Allocator.Persistent);
                geBuilder.Dispose();
            }

            var mapRef = builder.CreateBlobAssetReference<GEConfigBlobMap>(Allocator.Persistent);
            builder.Dispose();

            var entity = GetEntity(TransformUsageFlags.None);
            AddComponent(entity, new GEConfigLibrary { Map = mapRef });
        }

        private static void FillBlobArray(ref BlobBuilder b, ref BlobArray<int> arr, int[] src)
        {
            if (src == null || src.Length == 0) return;
            var a = b.Allocate(ref arr, src.Length);
            for (int i = 0; i < src.Length; i++) a[i] = src[i];
        }
    }
}
```

**合理性**：Luban 的价值在于结构化数据，BlobAsset 是 ECS 中存储只读配置数据的标准方案。烘焙后运行时访问 `BlobAsset` 是零分配、Cache 友好的，且完全 Burst 兼容。

### 3.2 Tag 系统重构（Burst 友好的层级 Tag）


**重构方案**：Tag 数据内嵌到 ASC 组件，层级关系预计算为 Singleton BlobAsset。

```csharp
// ============================================================
// [新] ASC 的 Tag 数据组件（直接内嵌，无需 DynamicBuffer）
// 文件：Assets/GAS/Runtime/Tag/Component/CTagContainer.cs
// ============================================================
using Unity.Entities;
using Unity.Collections;

namespace GAS.Runtime
{
    // 使用 FixedList 避免 DynamicBuffer 的间接访问
    // 大多数单位的 Tag 数量不超过 32 个
    public struct CTagContainer : IComponentData
    {
        // 固定 Tag（配置赋予，不随 GE 变化）
        public FixedList128Bytes<int> FixedTags;
        // 临时 Tag（GE / Ability 赋予，有生命周期）
        public FixedList128Bytes<int> TemporaryTags;
        // 脏标记，驱动依赖 Tag 的系统重新计算
        public bool IsDirty;
    }

    // Tag 层级关系的 Blob（Baking 期从 Luban 生成）
    // 每个 Tag 的"祖先链"预计算好，查询时 O(1)
    public struct TagHierarchyBlob
    {
        // tagId -> 该 tag 及其所有祖先 tag 的集合（用于 HasTag 的层级匹配）
        public BlobArray<int> TagIds;
        public BlobArray<BlobArray<int>> AncestorSets; // AncestorSets[i] = TagIds[i] 的所有祖先
    }

    public struct TagHierarchySingleton : IComponentData
    {
        public BlobAssetReference<TagHierarchyBlob> Hierarchy;
    }
}
```

```csharp
// ============================================================
// [新] Tag 查询工具（纯静态，Burst 兼容）
// 文件：Assets/GAS/Runtime/Tag/TagQueryUtil.cs
// ============================================================
using Unity.Burst;
using Unity.Collections;
using Unity.Entities;

namespace GAS.Runtime
{
    [BurstCompile]
    public static class TagQueryUtil
    {
        // 检查 container 是否包含 tagId（含层级匹配）
        [BurstCompile]
        public static bool HasTag(
            in CTagContainer container,
            int tagId,
            in TagHierarchyBlob hierarchy)
        {
            // 先检查精确匹配
            for (int i = 0; i < container.FixedTags.Length; i++)
                if (IsTagOrAncestor(container.FixedTags[i], tagId, in hierarchy)) return true;
            for (int i = 0; i < container.TemporaryTags.Length; i++)
                if (IsTagOrAncestor(container.TemporaryTags[i], tagId, in hierarchy)) return true;
            return false;
        }

        [BurstCompile]
        public static bool HasAllTags(
            in CTagContainer container,
            in BlobArray<int> required,
            in TagHierarchyBlob hierarchy)
        {
            for (int r = 0; r < required.Length; r++)
                if (!HasTag(in container, required[r], in hierarchy)) return false;
            return true;
        }

        [BurstCompile]
        public static bool HasAnyTag(
            in CTagContainer container,
            in BlobArray<int> tags,
            in TagHierarchyBlob hierarchy)
        {
            for (int r = 0; r < tags.Length; r++)
                if (HasTag(in container, tags[r], in hierarchy)) return true;
            return false;
        }

        // 判断 ownedTag 是否是 queryTag 或其子孙（即 queryTag 是 ownedTag 的祖先）
        [BurstCompile]
        private static bool IsTagOrAncestor(int ownedTag, int queryTag, in TagHierarchyBlob hierarchy)
        {
            if (ownedTag == queryTag) return true;
            // 在预计算的祖先集合中查找
            int idx = BinarySearch(in hierarchy.TagIds, ownedTag);
            if (idx < 0) return false;
            ref var ancestors = ref hierarchy.AncestorSets[idx];
            for (int i = 0; i < ancestors.Length; i++)
                if (ancestors[i] == queryTag) return true;
            return false;
        }

        [BurstCompile]
        private static int BinarySearch(in BlobArray<int> arr, int target)
        {
            int lo = 0, hi = arr.Length - 1;
            while (lo <= hi)
            {
                int mid = (lo + hi) >> 1;
                if (arr[mid] == target) return mid;
                if (arr[mid] < target) lo = mid + 1;
                else hi = mid - 1;
            }
            return -1;
        }
    }
}
```

### 3.3 Ability 逻辑重构（消灭 MCAbilityLogic，解锁 Burst）


**重构方案**：将 Ability 逻辑拆分为两类：
- **数据驱动型 Ability**（配置即逻辑）：完全在 ECS 内，全 Burst
- **自定义逻辑型 Ability**：通过 `IAbilityProcessor` 接口 + 标记组件，System 分发，OOP 逻辑只在 OOP 层执行

```csharp
// ============================================================
// [新] Ability 的 ECS 核心数据组件
// 文件：Assets/GAS/Runtime/Ability/Component/CAbilityCore.cs
// ============================================================
using Unity.Entities;
using Unity.Collections;

namespace GAS.Runtime
{
    // Ability 的核心静态数据（来自 BlobAsset，Burst 友好）

        public int Level;
        public Entity Owner;                              // ASC Entity
        public BlobAssetReference<AbilityConfigBlob> Config; // 配置引用
    }

    public struct AbilityConfigBlob
    {
        public int Code;
        public FixedString64Bytes Name;
        public int CooldownGEConfigId;   // 0 = 无 CD
        public int CostGEConfigId;       // 0 = 无消耗
        public int CustomLogicTypeId;    // 0 = 纯数据驱动，>0 = 自定义逻辑类型

        public BlobArray<int> ActivationRequiredTags;
        public BlobArray<int> ActivationBlockedTags;

    public struct CAbilityCancelCmd : IComponentData, IEnableableComponent { }

    // 自定义逻辑的事件输出（ECS → OOP 的单向通道）

        public int Frame;
```

```csharp
// ============================================================
// [新] STryActivateAbility（纯 ECS，全 Burst）
// 文件：Assets/GAS/Runtime/System/Ability/STryActivateAbility.cs
// ============================================================
using Unity.Burst;
using Unity.Entities;
using Unity.Collections;

namespace GAS.Runtime
{
    [UpdateInGroup(typeof(SGAbility))]
    [BurstCompile] // 现在可以 Burst 了！
    public partial struct STryActivateAbility : ISystem
    {
        private ComponentLookup<CTagContainer> _tagContainerLookup;
        private ComponentLookup<CAbilityRuntimeState> _runtimeStateLookup;
        private BufferLookup<BAbilityEvent> _eventBufferLookup;
        private SingletonTagHierarchy _tagHierarchy; // 缓存 Singleton

        [BurstCompile]
        public void OnCreate(ref SystemState state)
        {
            state.RequireForUpdate<CAbilityActivateCmd>();
            state.RequireForUpdate<TagHierarchySingleton>();
            _tagContainerLookup = state.GetComponentLookup<CTagContainer>(true);
            _runtimeStateLookup = state.GetComponentLookup<CAbilityRuntimeState>();
            _eventBufferLookup = state.GetBufferLookup<BAbilityEvent>();
        }

        [BurstCompile]
        public void OnUpdate(ref SystemState state)
        {
            _tagContainerLookup.Update(ref state);
            _runtimeStateLookup.Update(ref state);
            _eventBufferLookup.Update(ref state);

            var globalTimer = SystemAPI.GetSingleton<GlobalTimer>();
            var tagHierarchy = SystemAPI.GetSingleton<TagHierarchySingleton>();

            var ecb = new EntityCommandBuffer(Allocator.Temp);

            foreach (var (activateCmd, core, runtimeState, abilityEntity) in
                SystemAPI.Query<
                    EnabledRefRW<CAbilityActivateCmd>,
                    RefRO<CAbilityCore>,
                    RefRW<CAbilityRuntimeState>>()
                    .WithEntityAccess())
            {
                // 禁用命令标记（IEnableableComponent，无 Archetype 变更，Burst 友好）
                activateCmd.ValueRW = false;

                var result = CheckCanActivate(
                    in core.ValueRO,
                    in globalTimer,
                    in tagHierarchy,
                    ref _tagContainerLookup);

                if (result == AbilityActivationResult.Success)
                {
                    runtimeState.ValueRW.IsActive = true;
                    runtimeState.ValueRW.ActivateFrame = globalTimer.Frame;

                    // 添加 ActivationOwnedTags 到 ASC
                    ref var cfg = ref core.ValueRO.Config.Value;
                    if (cfg.ActivationOwnedTags.Length > 0 &&
                        _tagContainerLookup.HasComponent(core.ValueRO.Owner))
                    {
                        // 通过 ECB 写入，避免在 Lookup 中直接修改
                        ecb.SetComponent(core.ValueRO.Owner,
                            AddTemporaryTags(
                                _tagContainerLookup[core.ValueRO.Owner],
                                in cfg.ActivationOwnedTags));
                    }
                }

                // 写入事件 Buffer（ECS → OOP 的单向通道）
                if (_eventBufferLookup.HasBuffer(core.ValueRO.Owner))
                {
                    _eventBufferLookup[core.ValueRO.Owner].Add(new BAbilityEvent
                    {
                        EventType = AbilityEventType.ActivateResult,
                        AbilityCode = core.ValueRO.Code,
                        Frame = globalTimer.Frame,
                        Result = result
                    });
                }
            }

            ecb.Playback(state.EntityManager);
            ecb.Dispose();
        }

        [BurstCompile]
        private static AbilityActivationResult CheckCanActivate(
            in CAbilityCore core,
            in GlobalTimer timer,
            in TagHierarchySingleton tagHierarchySingleton,
            ref ComponentLookup<CTagContainer> tagLookup)
        {
            // CD 检查
            // （CAbilityRuntimeState.CooldownEndFrame 由 GE 系统写入）

            // Tag 检查（全 Burst）
            if (!tagLookup.HasComponent(core.Owner))
                return AbilityActivationResult.FailOtherReason;

            var ownerTags = tagLookup[core.Owner];
            ref var cfg = ref core.Config.Value;
            ref var hierarchy = ref tagHierarchySingleton.Hierarchy.Value;

            if (!TagQueryUtil.HasAllTags(in ownerTags, in cfg.ActivationRequiredTags, in hierarchy))
                return AbilityActivationResult.FailTagRequirement;

            if (TagQueryUtil.HasAnyTag(in ownerTags, in cfg.ActivationBlockedTags, in hierarchy))
                return AbilityActivationResult.FailTagBlocked;

            return AbilityActivationResult.Success;
        }

        [BurstCompile]
        private static CTagContainer AddTemporaryTags(
            CTagContainer container,
            in BlobArray<int> tags)
        {
            for (int i = 0; i < tags.Length; i++)
                if (!container.TemporaryTags.Contains(tags[i]))
                    container.TemporaryTags.Add(tags[i]);
            container.IsDirty = true;
            return container;
        }

        [BurstCompile]
        public void OnDestroy(ref SystemState state) { }
    }
}
```

### 3.4 事件管线重构（ECS 事件 Buffer → OOP 分发）


**重构方案**：ECS System 只写入事件 Buffer，OOP 层在主线程读取并分发。

```csharp

// 文件：Assets/GAS/Runtime/General/Event/GASEventBuffer.cs
// ============================================================
using Unity.Entities;

namespace GAS.Runtime
{
    // 通用 GAS 事件（写入 ASC Entity 的 Buffer）
    public struct BGASEvent : IBufferElementData
    {
        public GASEventType Type;
        public int SubjectCode;    // Ability Code / GE Config Id / Attr Code
        public int IntValue;       // 通用整型载荷
        public float FloatValue;   // 通用浮点载荷
        public int Frame;
    }

    public enum GASEventType : byte

        AbilityEnd,
        AbilityCancel,
```

```csharp
// ============================================================
// [新] OOP 外壳：AbilitySystemFacade
// 职责：读取 ECS 事件 Buffer，分发给 OOP 订阅者
// 文件：Assets/GAS/Runtime/Bridge/AbilitySystemFacade.cs
// ============================================================
using System;
using System.Collections.Generic;
using Unity.Entities;

namespace GAS.Runtime
{
    /// <summary>
    /// OOP 外壳层。这是 ECS GamePlay 核心与外界业务（UI/网络/输入）的唯一接口。
    /// 不持有任何 GamePlay 状态，只做：
    ///   1. 将 OOP 命令转换为 ECS 命令组件（写入）
    ///   2. 将 ECS 事件 Buffer 转换为 OOP 事件（读取 + 分发）
    /// </summary>
    public class AbilitySystemFacade
    {
        private readonly Entity _ascEntity;
        private static EntityManager _em => GASManager.EntityManager;

        // OOP 事件订阅（只在 OOP 层，不进入 ECS）
        private readonly Dictionary<int, List<Action<AbilityActivationResult>>> _onActivateResult = new();
        private readonly Dictionary<int, List<Action>> _onAbilityEnd = new();
        private readonly List<Action<int, float, float>> _onAttrChanged = new(); // (attrCode, oldVal, newVal)

        public AbilitySystemFacade(Entity ascEntity)
        {
            _ascEntity = ascEntity;
        }

        // ── 命令写入（OOP → ECS）──────────────────────────────

        /// <summary>
        /// 激活技能：通过 IEnableableComponent 标记，无 Archetype 变更，Burst 友好
        /// </summary>
        public void TryActivateAbility(int abilityCode)
        {
            var abilityEntity = FindAbilityEntity(abilityCode);
            if (abilityEntity == Entity.Null) return;
            _em.SetComponentEnabled<CAbilityActivateCmd>(abilityEntity, true);
        }

        public void TryEndAbility(int abilityCode)
        {
            var abilityEntity = FindAbilityEntity(abilityCode);
            if (abilityEntity == Entity.Null) return;
            _em.SetComponentEnabled<CAbilityEndCmd>(abilityEntity, true);
        }

        public void ApplyGameplayEffect(int geConfigId, Entity sourceAsc)
        {
            // 创建 GE 命令 Entity（轻量，只含命令数据）
            var cmdEntity = _em.CreateEntity();
            _em.AddComponentData(cmdEntity, new CGEApplyCommand
            {
                ConfigId = geConfigId,
                TargetAsc = _ascEntity,
                SourceAsc = sourceAsc,
                Level = 1
            });
        }

        // ── 事件读取（ECS → OOP）─────────────────────────────
        // 在主线程每帧调用（例如在 MonoBehaviour.Update 中）

        public void FlushEvents()
        {
            if (!_em.Exists(_ascEntity)) return;
            if (!_em.HasBuffer<BGASEvent>(_ascEntity)) return;

            var buffer = _em.GetBuffer<BGASEvent>(_ascEntity);
            for (int i = 0; i < buffer.Length; i++)
            {
                var evt = buffer[i];
                switch (evt.Type)
                {
                    case GASEventType.AbilityActivateResult:
                        DispatchActivateResult(evt.SubjectCode, (AbilityActivationResult)evt.IntValue);
                        break;
                    case GASEventType.AbilityEnd:
                        DispatchAbilityEnd(evt.SubjectCode);
                        break;
                    case GASEventType.AttributeChanged:
                        DispatchAttrChanged(evt.SubjectCode, evt.FloatValue,
                            BitConverter.Int32BitsToSingle(evt.IntValue));
                        break;
                }
            }
            buffer.Clear(); // 消费完毕，清空
        }

        // ── 事件订阅 API ──────────────────────────────────────

        public void OnActivateResult(int abilityCode, Action<AbilityActivationResult> callback)
        {
            if (!_onActivateResult.TryGetValue(abilityCode, out var list))
                _onActivateResult[abilityCode] = list = new List<Action<AbilityActivationResult>>();
            list.Add(callback);
        }

        public void OnAbilityEnd(int abilityCode, Action callback)
        {
            if (!_onAbilityEnd.TryGetValue(abilityCode, out var list))
                _onAbilityEnd[abilityCode] = list = new List<Action>();
            list.Add(callback);
        }

        public void OnAttributeChanged(Action<int, float, float> callback)
            => _onAttrChanged.Add(callback);

        // ── 属性查询（只读，直接访问 ECS 数据）──────────────

        public float GetAttrCurrentValue(int attrSetCode, int attrCode)
        {
            // 直接读 ECS 组件，无 OOP 中间层
            if (!_em.HasBuffer<BEAttrSet>(_ascEntity)) return 0f;
            var attrSets = _em.GetBuffer<BEAttrSet>(_ascEntity, true);
            foreach (var set in attrSets)
                if (set.Code == attrSetCode)
                    foreach (var attr in set.Attributes)
                        if (attr.Code == attrCode) return attr.CurrentValue;
            return 0f;
        }

        // ── 内部工具 ──────────────────────────────────────────

        private Entity FindAbilityEntity(int abilityCode)
        {
            if (!_em.HasBuffer<BAbility>(_ascEntity)) return Entity.Null;
            var buffer = _em.GetBuffer<BAbility>(_ascEntity, true);
            foreach (var b in buffer)
            {
                if (!_em.Exists(b.Ability)) continue;
                var core = _em.GetComponentData<CAbilityCore>(b.Ability);
                if (core.Code == abilityCode) return b.Ability;
            }
            return Entity.Null;
        }

        private void DispatchActivateResult(int code, AbilityActivationResult result)
        {
            if (_onActivateResult.TryGetValue(code, out var list))
                foreach (var cb in list) cb(result);
        }

        private void DispatchAbilityEnd(int code)
        {
            if (_onAbilityEnd.TryGetValue(code, out var list))
                foreach (var cb in list) cb();
        }

        private void DispatchAttrChanged(int code, float oldVal, float newVal)
        {
            foreach (var cb in _onAttrChanged) cb(code, oldVal, newVal);
        }
    }
}
```

### 3.5 Attribute 系统重构（全 Burst 属性计算）


```csharp
// ============================================================
// [新] SUpdateAttributeCurrentValue（全 Burst）
// 文件：Assets/GAS/Runtime/System/Attribute/SUpdateAttributeCurrentValue.cs
// ============================================================
using Unity.Burst;
using Unity.Entities;
using Unity.Collections;

namespace GAS.Runtime
{
    [UpdateInGroup(typeof(SGAttribute))]
    [BurstCompile]
    public partial struct SUpdateAttributeCurrentValue : ISystem
    {
        [BurstCompile]
        public void OnCreate(ref SystemState state)
        {
            state.RequireForUpdate<CAttributeIsDirty>();
        }

        [BurstCompile]
        public void OnUpdate(ref SystemState state)
        {
            var ecb = new EntityCommandBuffer(Allocator.Temp);

            // 查询所有 GE Modifier Buffer（用于计算属性）
            var geModifierLookup = SystemAPI.GetBufferLookup<BActiveModifier>(true);

            foreach (var (_, attrSets, activeGEs, ascEntity) in
                SystemAPI.Query<
                    RefRO<CAttributeIsDirty>,
                    DynamicBuffer<BEAttrSet>,
                    DynamicBuffer<BGameplayEffect>>()
                    .WithEntityAccess())
            {
                // 重置所有属性的 CurrentValue = BaseValue
                for (int s = 0; s < attrSets.Length; s++)
                {
                    var set = attrSets[s];
                    for (int a = 0; a < set.Attributes.Length; a++)
                    {
                        var attr = set.Attributes[a];
                        attr.CurrentValue = attr.BaseValue;
                        set.Attributes[a] = attr;
                    }
                    attrSets[s] = set;
                }

                // 遍历所有激活的 GE，累加 Modifier
                for (int g = 0; g < activeGEs.Length; g++)
                {
                    var geEntity = activeGEs[g].Effect;
                    if (!geModifierLookup.HasBuffer(geEntity)) continue;

                    var modifiers = geModifierLookup[geEntity];
                    for (int m = 0; m < modifiers.Length; m++)
                    {
                        var mod = modifiers[m];
                        ApplyModifier(attrSets, mod.AttrSetCode, mod.AttrCode,
                            mod.Operation, mod.Magnitude);
                    }
                }

                ecb.RemoveComponent<CAttributeIsDirty>(ascEntity);

                // 写入属性变更事件
                // （通过 BGASEvent Buffer 通知 OOP 层）
            }

            ecb.Playback(state.EntityManager);
            ecb.Dispose();
        }

        [BurstCompile]
        private static void ApplyModifier(
            DynamicBuffer<BEAttrSet> attrSets,
            int attrSetCode, int attrCode,
            GEOperation op, float magnitude)
        {
            for (int s = 0; s < attrSets.Length; s++)
            {
                if (attrSets[s].Code != attrSetCode) continue;
                var set = attrSets[s];
                for (int a = 0; a < set.Attributes.Length; a++)
                {
                    if (set.Attributes[a].Code != attrCode) continue;
                    var attr = set.Attributes[a];
                    attr.CurrentValue = op switch
                    {
                        GEOperation.Add => attr.CurrentValue + magnitude,
                        GEOperation.Multiply => attr.CurrentValue * magnitude,
                        GEOperation.Override => magnitude,
                        _ => attr.CurrentValue
                    };
                    set.Attributes[a] = attr;
                    attrSets[s] = set;
                    return;
                }
            }
        }

        [BurstCompile]
        public void OnDestroy(ref SystemState state) { }
    }

    // 激活的 Modifier 缓存（由 SGActivateEffect 写入，SGAttribute 读取）
    public struct BActiveModifier : IBufferElementData
    {
        public int AttrSetCode;
        public int AttrCode;
        public GEOperation Operation;
        public float Magnitude;
    }
```

```csharp
// 文件：Assets/GAS/Runtime/System/GameplayEffect/SProcessGEApplyCommand.cs
// ============================================================
using Unity.Burst;
using Unity.Entities;
using Unity.Collections;

namespace GAS.Runtime
{
    [UpdateInGroup(typeof(SGEffectCreate))]
    [BurstCompile]
    public partial struct SProcessGEApplyCommand : ISystem
    {
        [BurstCompile]
        public void OnCreate(ref SystemState state)
        {
            state.RequireForUpdate<CGEApplyCommand>();
        }

        [BurstCompile]
        public void OnUpdate(ref SystemState state)
        {
            var configLibrary = SystemAPI.GetSingleton<GEConfigLibrary>();
            var ecb = new EntityCommandBuffer(Allocator.Temp);

            foreach (var (cmd, cmdEntity) in
                SystemAPI.Query<RefRO<CGEApplyCommand>>().WithEntityAccess())
            {
                // 从 BlobAsset 查找配置（零分配，Burst 友好）
                ref var map = ref configLibrary.Map.Value;
                int cfgIdx = BinarySearchConfig(in map.Keys, cmd.ValueRO.ConfigId);
                if (cfgIdx < 0)
                {
                    ecb.DestroyEntity(cmdEntity);
                    continue;
                }

                ref var cfg = ref map.Values[cfgIdx].Value;

                // 创建 GE 实例 Entity（从 BlobAsset 读取配置，无 JSON 解析）
                var geEntity = ecb.CreateEntity();
                ecb.AddComponent(geEntity, new CEffectBasicInfo
                {
                    ConfigId = cfg.ConfigId,
                    Name = cfg.Name
                });
                ecb.AddComponent(geEntity, new CEffectInUsage
                {
                    Source = cmd.ValueRO.SourceAsc,
                    Target = cmd.ValueRO.TargetAsc,
                    Level = cmd.ValueRO.Level
                });

                // 根据配置类型添加对应组件（无需手动拼装 ComponentConfig[]）
                if (cfg.DurationType != GEDurationType.Instant)
                {
                    int duration = cmd.ValueRO.OverrideDuration > 0
                        ? cmd.ValueRO.OverrideDuration
                        : cfg.Duration;
                    ecb.AddComponent(geEntity, new CDuration
                    {
                        duration = duration,
                        timeUnit = cfg.TimeUnit
                    });
                }

                if (cfg.HasStacking)
                    ecb.AddComponent(geEntity, new CStacking
                    {
                        StackType = cfg.StackType,
                        LimitCount = cfg.StackLimitCount,
                        EffectDurationRefreshPolicy = cfg.DurationRefreshPolicy,
                        EffectExpirationPolicy = cfg.ExpirationPolicy
                    });

                // 标记为待处理（进入 GE 管线）
                ecb.AddComponent<WipApplyEffect>(geEntity);

                ecb.DestroyEntity(cmdEntity);
            }

            ecb.Playback(state.EntityManager);
            ecb.Dispose();
        }

        [BurstCompile]
        private static int BinarySearchConfig(in BlobArray<int> keys, int target)
        {
            int lo = 0, hi = keys.Length - 1;
            while (lo <= hi)
            {
                int mid = (lo + hi) >> 1;
                if (keys[mid] == target) return mid;
                if (keys[mid] < target) lo = mid + 1;
                else hi = mid - 1;
            }
            return -1;
        }

        [BurstCompile]
        public void OnDestroy(ref SystemState state) { }
    }
}
```

## 八、EntityHelper 的消除方案

当前 `EntityHelper` 的静态 ECB 状态是为了解决"在 ECB 模式下读取尚未 Playback 的组件"这个问题。重构后，这个问题通过以下方式消除：

1. **命令组件改用 `IEnableableComponent`**：`SetComponentEnabled` 是即时生效的，不需要 ECB，也不需要 `_pendingComponents` 字典
2. **读写分离**：System 通过 `ComponentLookup`（只读）读取数据，通过 ECB（只写）修改数据，同一帧内不存在"读自己写的数据"的需求
3. **跨 System 通信通过 Buffer**：`BGASEvent`、`BActiveModifier` 等 Buffer 作为 System 间的数据通道，避免直接的跨 System 组件读写

```csharp
// ============================================================
// [新] 消除 EntityHelper 后的 ASC 创建方式
// 文件：Assets/GAS/Runtime/General/GASManager.cs（精简版）
// ============================================================
using Unity.Entities;

namespace GAS.Runtime
{
    public static class GASManager
    {
        public static EntityManager EntityManager => ExWorld.EntityManager;
        private static World ExWorld => World.DefaultGameObjectInjectionWorld;

        // 创建 ASC Entity（纯 ECS，无 OOP 绑定字典）
        public static Entity CreateAscEntity(int presetId)
        {
            var em = EntityManager;
            var entity = em.CreateEntity();

            // 从 BlobAsset 预设加载初始配置

            ref var preset = ref FindPreset(ref presetLibrary, presetId);

            em.AddComponentData(entity, new CTagContainer());
            em.AddBuffer<BEAttrSet>(entity);
            em.AddBuffer<BAbility>(entity);
            em.AddBuffer<BGameplayEffect>(entity);
            em.AddBuffer<BGASEvent>(entity); // 事件 Buffer（ECS → OOP）

            // 初始化属性集（从 BlobAsset 读取，零分配）
            InitAttrSets(em, entity, ref preset);

            return entity;
        }

        public static void DestroyAscEntity(Entity entity)
        {
            if (EntityManager.Exists(entity))
                EntityManager.DestroyEntity(entity);
            // 无需维护 OOP 绑定字典，直接销毁即可
        }

        private static ref ASCPresetBlob FindPreset(
            ref ASCPresetLibrary library, int presetId)
        {
            // BlobAsset 二分查找，Burst 友好
            ref var map = ref library.Map.Value;
            // ... 二分查找逻辑
            return ref map.Values[0].Value; // 简化示意
        }

        private static void InitAttrSets(
            EntityManager em, Entity entity, ref ASCPresetBlob preset)
        {
            var attrBuffer = em.GetBuffer<BEAttrSet>(entity);
            for (int i = 0; i < preset.AttrSets.Length; i++)
            {
                ref var setBlob = ref preset.AttrSets[i];
                var set = new BEAttrSet { Code = setBlob.Code };
                for (int a = 0; a < setBlob.Attributes.Length; a++)
                    set.Attributes.Add(new EAttr
                    {
                        Code = setBlob.Attributes[a].Code,
                        BaseValue = setBlob.Attributes[a].DefaultValue,
                        CurrentValue = setBlob.Attributes[a].DefaultValue
                    });
                attrBuffer.Add(set);
            }
        }
    }
```

## 九、总结：重构的本质

这次重构的核心不是"把 OOP 代码改成 ECS 代码"，而是**重新定义每一层的职责边界**：

```
职责边界重新划分：

ECS GamePlay Core（纯血）
  ├── 拥有所有 GamePlay 状态（Tag、Attr、GE、Ability 的运行时数据）
  ├── 执行所有 GamePlay 逻辑（激活检查、属性计算、GE 生命周期）
  ├── 通过 BGASEvent Buffer 向上输出事件（单向，不依赖 OOP）
  └── 通过 IEnableableComponent / 命令 Entity 接收来自 OOP 的命令（单向）

OOP Bridge Layer（外壳）
  ├── 不持有任何 GamePlay 状态
  ├── 将 OOP 命令（TryActivateAbility）转换为 ECS 命令（SetComponentEnabled）
  ├── 将 ECS 事件（BGASEvent Buffer）转换为 OOP 事件（C# Action 回调）
  └── 提供只读查询接口（直接读 ECS 组件，无缓存）

Luban Data Layer（配置）
  ├── Excel 定义数据结构（GE、Ability、AttrSet、Tag 层级）
  ├── Luban 生成 C# 常量 + 加载 API
  └── Baker 将 Luban 数据烘焙为 BlobAsset（运行时零解析）
```
