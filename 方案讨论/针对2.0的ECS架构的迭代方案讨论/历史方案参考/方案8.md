## 二、重构核心原则

```
┌─────────────────────────────────────────────────────────────┐
│                    业务层 (OOP Shell)                        │
│  UnitFacade / AbilityHandle / GEHandle                      │
│  职责：仅作为 Entity 句柄，供 UI/动画/网络等 OOP 模块使用    │
│  禁止：持有任何运行时状态，禁止驱动 ECS 逻辑                 │
├─────────────────────────────────────────────────────────────┤
│                    GAS ECS 核心层 (纯血)                     │
│  Components / Systems / Jobs / BlobAssets                   │
│  职责：所有 GAS 逻辑，全部 Burst 编译，支持并行 Job          │
│  禁止：任何托管类引用，任何 GC 分配                          │
├─────────────────────────────────────────────────────────────┤
│                    数据层 (Luban + BlobAsset)                │
│  Excel → Luban → BlobAsset Builder → BlobAssetReference     │
│  职责：零拷贝配置数据，编译期类型安全                        │
└─────────────────────────────────────────────────────────────┘
```

## 三、重构方案：完整代码解读

### 3.1 数据层重构：Luban 直接生成 BlobAsset Builder


**重构方向**：Luban 生成 `BlobAssetBuilder` 代码，在 `ISystem.OnCreate` 阶段一次性构建所有 `BlobAsset`，运行时通过 `BlobAssetReference<T>` 零拷贝访问。

```csharp
// ============================================================
// [数据层] Luban 生成的 BlobAsset 结构定义
// 文件: Assets/GAS/Runtime/Data/GASBlobData.cs
// ============================================================

using Unity.Entities;
using Unity.Collections;

namespace GAS.Runtime.Data
{
    // Luban 从 #exgas.attribute.xlsx 生成此结构
    public struct AttributeDefBlob
    {
        public int Code;
        public int AttrSetCode;
        public float BaseValue;
        public float MinValue;
        public float MaxValue;
        public BlobString Name;
    }

    public struct AttributeSetDefBlob
    {
        public int Code;
        public BlobArray<AttributeDefBlob> Attributes;
    }

    // Luban 从 #exgas.gameplayEffect.xlsx 生成此结构
    public struct EffectModifierBlob
    {
        public int AttrSetCode;
        public int AttrCode;
        public GEOperation Operation;
        public float Magnitude;
        public int MmcCode; // 0 = 无 MMC
    }

    public struct GameplayEffectDefBlob
    {
        public int Code;
        public BlobString Name;
        public EffectDurationType DurationType;
        public int Duration;          // 帧数，-1=无限
        public int Period;            // 0=无周期
        public BlobArray<int> GrantedTags;
        public BlobArray<int> ApplicationRequiredTags;
        public BlobArray<int> OngoingRequiredTags;
        public BlobArray<int> RemoveEffectWithTags;
        public BlobArray<EffectModifierBlob> Modifiers;
    }

    // Luban 从 #exgas.ability.xlsx 生成此结构
    public struct AbilityDefBlob
    {
        public int Code;
        public BlobString Name;
        public int CooldownGECode;    // 冷却 GE 的 Code，0=无冷却
        public int CostGECode;        // 消耗 GE 的 Code，0=无消耗
        public BlobArray<int> AssetTags;
        public BlobArray<int> ActivationOwnedTags;
        public BlobArray<int> ActivationRequiredTags;
        public BlobArray<int> ActivationBlockedTags;
        public BlobArray<int> CancelAbilityWithTags;
    }

    // 全局配置注册表 Singleton Component
    public struct GASConfigRegistry : IComponentData
    {
        public BlobAssetReference<BlobArray<GameplayEffectDefBlob>> EffectDefs;
        public BlobAssetReference<BlobArray<AbilityDefBlob>> AbilityDefs;
        public BlobAssetReference<BlobArray<AttributeSetDefBlob>> AttrSetDefs;
    }
}
```

```csharp
// ============================================================
// [数据层] Luban 生成的 BlobAsset 构建系统
// 文件: Assets/GAS/Runtime/System/Core/SBuildGASConfig.cs
// ============================================================
// 这个 System 在 InitializationSystemGroup 中运行一次，
// 将 Luban 生成的 JSON 数据转换为 BlobAsset 并注册为 Singleton。
// 关键：此后所有运行时访问都是零拷贝的 BlobAssetReference。

using Unity.Entities;
using Unity.Collections;
using GAS.Runtime.Data;

namespace GAS.Runtime
{
    [UpdateInGroup(typeof(InitializationSystemGroup))]
    public partial struct SBuildGASConfig : ISystem
    {
        public void OnCreate(ref SystemState state)
        {
            // 从 XLuban 读取原始数据（仅在初始化时执行一次）
            var rawEffects = XLuban.GetAllGameplayEffectConfigs(); // 返回 C# 列表

            // 构建 BlobAsset
            var builder = new BlobBuilder(Allocator.Temp);
            ref var root = ref builder.ConstructRoot<BlobArray<GameplayEffectDefBlob>>();
            var effectArray = builder.Allocate(ref root, rawEffects.Count);

            for (int i = 0; i < rawEffects.Count; i++)
            {
                var raw = rawEffects[i];
                effectArray[i].Code = raw.Code;
                effectArray[i].Duration = raw.Duration;
                // ... 填充其他字段
                builder.AllocateString(ref effectArray[i].Name, raw.Name);

                var modArray = builder.Allocate(ref effectArray[i].Modifiers, raw.Modifiers.Count);
                for (int j = 0; j < raw.Modifiers.Count; j++)
                {
                    modArray[j] = new EffectModifierBlob
                    {
                        AttrSetCode = raw.Modifiers[j].AttrSetCode,
                        AttrCode = raw.Modifiers[j].AttrCode,
                        Operation = raw.Modifiers[j].Operation,
                        Magnitude = raw.Modifiers[j].Magnitude,
                    };
                }
            }

            var blobRef = builder.CreateBlobAssetReference<BlobArray<GameplayEffectDefBlob>>(Allocator.Persistent);
            builder.Dispose();

            // 注册为 Singleton，此后所有 System 通过 SystemAPI.GetSingleton<GASConfigRegistry>() 访问
            var registryEntity = state.EntityManager.CreateSingleton<GASConfigRegistry>();
            state.EntityManager.SetComponentData(registryEntity, new GASConfigRegistry
            {
                EffectDefs = blobRef,
                // ... 其他 BlobAsset
            });

            // 只运行一次
            state.Enabled = false;
        }
    }
}
```

**为什么这样设计**：
- `BlobAsset` 存储在非托管内存中，Burst Job 可以直接访问，无需任何 GC 分配
- 配置数据从"每次创建 GE Entity 时解析 JSON"变为"启动时一次性构建，运行时零拷贝"
- Luban 的职责从"生成 JSON + 常量"扩展为"生成 BlobAsset Builder 代码"，完全解放其潜力

### 3.2 ECS 核心层重构：纯血 Ability 系统


**重构方向**：用 `IAbilityProcessor` 接口 + `ISystem` 替代托管类。对于需要自定义逻辑的 Ability，使用 ECS 的 `IComponentData` 存储状态，用独立的 `ISystem` 处理逻辑。

```csharp
// ============================================================
// [ECS核心] Ability 核心组件定义
// 文件: Assets/GAS/Runtime/Ability/Component/AbilityComponents.cs
// ============================================================

using Unity.Entities;
using Unity.Collections;

namespace GAS.Runtime
{
    // Ability 的静态配置引用（指向 BlobAsset）
    public struct CAbilityDef : IComponentData
    {
        public int Code;
        public int Level;
        public Entity Owner; // ASC Entity
        // 直接引用 BlobAsset，零拷贝
        public BlobAssetReference<AbilityDefBlob> Def;

    public struct CAbilityActive : IComponentData, IEnableableComponent { }

    {
        public int CooldownEndFrame;

    public struct CAbilityActivateCmd : IComponentData { }
    public struct CAbilityEndCmd : IComponentData { }
    public struct CAbilityCancelCmd : IComponentData { }

    // AbilityTypeId 对应一个静态注册的 IAbilityProcessor 实现
    public struct CAbilityProcessor : IComponentData
    {
        public int ProcessorTypeId; // 注册表中的 ID，对应具体的处理逻辑
    }

    // 对于复杂参数，使用 DynamicBuffer 或 BlobAsset
    public struct CAbilityParam : IComponentData
    {
        public Entity TargetEntity;
        public float3 TargetPosition;
        public int IntParam;
        public float FloatParam;
    }
```

```csharp
// ============================================================
// [ECS核心] 纯血 Ability 激活系统（完全 Burst 编译）
// 文件: Assets/GAS/Runtime/System/Ability/STryActivateAbility.cs (重构版)
// ============================================================

using Unity.Burst;
using Unity.Entities;
using Unity.Collections;

namespace GAS.Runtime
{
    [UpdateInGroup(typeof(SGAbility))]
    [BurstCompile] // 现在可以完整 Burst 编译！
    public partial struct STryActivateAbility : ISystem
    {
        [BurstCompile]
        public void OnCreate(ref SystemState state)
        {
            state.RequireForUpdate<CAbilityActivateCmd>();
        }

        [BurstCompile]
        public void OnUpdate(ref SystemState state)
        {
            var ecb = new EntityCommandBuffer(Allocator.Temp);
            var tagLookup = SystemAPI.GetBufferLookup<BFixedTag>(true);
            var tempTagLookup = SystemAPI.GetBufferLookup<BTemporaryTag>(true);
            var attrLookup = SystemAPI.GetBufferLookup<BEAttrSet>(true);
            var resultBuffer = SystemAPI.GetSingletonBuffer<BAbilityActivationResult>();

            foreach (var (cmd, def, cooldown, entity) in SystemAPI
                .Query<RefRO<CAbilityActivateCmd>, RefRO<CAbilityDef>>()
                .WithPresent<CAbilityOnCooldown>()
                .WithEntityAccess())
            {
                var result = CheckCanActivate(entity, def.ValueRO, cooldown, tagLookup, attrLookup, state.EntityManager);

                if (result == AbilityActivationResult.Success)
                {
                    // 使用 IEnableableComponent，不触发 Archetype 变更
                    ecb.SetComponentEnabled<CAbilityActive>(entity, true);

                    // 添加 ActivationOwnedTags
                    ref var abilityDef = ref def.ValueRO.Def.Value;
                    var owner = def.ValueRO.Owner;
                    for (int i = 0; i < abilityDef.ActivationOwnedTags.Length; i++)
                        TagHelper.AddTemporaryTagECB(ref ecb, owner, entity, abilityDef.ActivationOwnedTags[i]);

                    // 取消被 CancelAbilityWithTags 标记的其他 Ability
                    // （通过写入 BAbilityActivationResult 事件队列通知）
                }

                // 写入结果事件（替代 GASEventCenter 委托字典）
                resultBuffer.Add(new BAbilityActivationResult
                {
                    AbilityEntity = entity,
                    Result = result
                });

                ecb.RemoveComponent<CAbilityActivateCmd>(entity);
            }

            ecb.Playback(state.EntityManager);
            ecb.Dispose();
        }

        [BurstCompile]
        private static AbilityActivationResult CheckCanActivate(
            Entity abilityEntity,
            in CAbilityDef def,
            in CAbilityOnCooldown cooldown,
            in BufferLookup<BFixedTag> tagLookup,
            in BufferLookup<BEAttrSet> attrLookup,
            EntityManager em)
        {
            // 检查冷却（纯数据操作，Burst 友好）
            var timer = SystemAPI.GetSingleton<GlobalTimer>();
            if (em.IsComponentEnabled<CAbilityOnCooldown>(abilityEntity) &&
                timer.Frame < cooldown.CooldownEndFrame)
                return AbilityActivationResult.FailCooldown;

            // 检查 Tag 条件（纯数据操作）
            var owner = def.Owner;
            ref var abilityDef = ref def.Def.Value;
            if (!TagHelper.HasAllTags(tagLookup[owner], abilityDef.ActivationRequiredTags))
                return AbilityActivationResult.FailTagRequirement;

            // 检查 Cost（纯数据操作）
            // ...

            return AbilityActivationResult.Success;
        }
    }
}
```

```csharp
// [ECS核心] 自定义 Ability 逻辑的正确 ECS 方式
// 文件: Assets/GAS/Runtime/Ability/FireballAbility.cs (业务代码示例)
// ============================================================
// 【关键设计】：自定义逻辑不再是"继承 AbilityLogicBase 的托管类"，
// 而是"为 Ability Entity 添加特定 IComponentData，由专属 ISystem 处理"。

using Unity.Burst;
using Unity.Entities;
using Unity.Mathematics;

namespace Game.Abilities
{
    // 1. 定义 Fireball Ability 的专属状态组件
    public struct CFireballAbilityState : IComponentData
    {
        public Entity ProjectileEntity;
        public float3 TargetPosition;
        public int CastStartFrame;
    }

    [UpdateInGroup(typeof(SGAbility))]
    [UpdateAfter(typeof(STryActivateAbility))]
    [BurstCompile] // 完全 Burst 编译！
    public partial struct SFireballAbilityTick : ISystem
    {
        [BurstCompile]
        public void OnUpdate(ref SystemState state)
        {
            var ecb = new EntityCommandBuffer(Allocator.Temp);
            var timer = SystemAPI.GetSingleton<GlobalTimer>();

            // 只处理激活状态的 Fireball Ability
            foreach (var (state_, fireballState, def, entity) in SystemAPI
                .Query<RefRO<CAbilityActive>, RefRW<CFireballAbilityState>, RefRO<CAbilityDef>>()
                .WithAll<CFireballAbilityTag>() // 用 Tag 区分 Ability 类型
                .WithEntityAccess())
            {
                // 纯数据操作，无托管类，完全 Burst
                int elapsed = timer.Frame - fireballState.ValueRO.CastStartFrame;

                if (elapsed >= 10) // 10帧后发射
                {
                    // 通过 ECB 创建投射物 Entity
                    var projectile = ecb.CreateEntity();
                    ecb.AddComponent(projectile, new CProjectile
                    {
                        TargetPosition = fireballState.ValueRO.TargetPosition,
                        Speed = 20f,
                        OwnerAsc = def.ValueRO.Owner
                    });

                    // 结束 Ability
                    ecb.AddComponent<CAbilityEndCmd>(entity);
                }
            }

            ecb.Playback(state.EntityManager);
            ecb.Dispose();
        }
    }
}
```

**为什么这样设计**：
- 每种 Ability 的逻辑由专属 `ISystem` 处理，而不是虚函数调用
- `ISystem` 可以完整 Burst 编译，支持 `IJobEntity` 并行处理
- Ability 状态存储在 `IComponentData` 中，完全符合 ECS 数据局部性原则
- 用 `IEnableableComponent` 替代 Add/Remove 标记组件，避免 Archetype 变更带来的 Chunk 迁移开销

### 3.3 属性系统重构：Burst 友好的脏标记计算

```csharp
// ============================================================
// [ECS核心] 属性组件重构（支持 Burst）
// 文件: Assets/GAS/Runtime/Attribute/Component/AttributeComponents.cs
// ============================================================

using Unity.Entities;
using Unity.Collections;

namespace GAS.Runtime
{
    // 单个属性的运行时数据（存储在 DynamicBuffer 中）
    public struct BAttribute : IBufferElementData
    {
        public int Code;
        public int AttrSetCode;
        public float BaseValue;
        public float CurrentValue;
        // 使用 bit flag 替代 bool，节省内存对齐开销
        public byte Flags; // bit0 = Dirty
        public bool Dirty
        {
            get => (Flags & 1) != 0;
            set => Flags = value ? (byte)(Flags | 1) : (byte)(Flags & ~1);
        }
    }

    // Modifier 存储在 ASC 的 DynamicBuffer 中（替代 MCModifiers 托管组件）
    public struct BActiveModifier : IBufferElementData
    {
        public int AttrSetCode;
        public int AttrCode;
        public GEOperation Operation;
        public float Magnitude;
        public Entity SourceGEEntity; // 用于 GE 移除时批量清理
    }

    // 脏标记：使用 IEnableableComponent 替代 Add/Remove
    public struct CAttributeDirty : IComponentData, IEnableableComponent { }
}
```

```csharp
// ============================================================
// [ECS核心] 属性计算系统（完全 Burst 编译）
// 文件: Assets/GAS/Runtime/System/Attribute/SUpdateAttributeCurrentValue.cs (重构版)
// ============================================================

using Unity.Burst;
using Unity.Entities;
using Unity.Collections;

namespace GAS.Runtime
{
    [UpdateInGroup(typeof(SGAttribute))]
    [BurstCompile] // 现在可以完整 Burst 编译！
    public partial struct SUpdateAttributeCurrentValue : ISystem
    {
        [BurstCompile]
        public void OnCreate(ref SystemState state)
        {
            state.RequireForUpdate<CAttributeDirty>();
        }

        [BurstCompile]
        public void OnUpdate(ref SystemState state)
        {
            // 使用 IJobEntity 并行处理所有脏 ASC
            var job = new RecalculateAttributeJob();
            state.Dependency = job.ScheduleParallel(state.Dependency);
        }

        [BurstCompile]
        private partial struct RecalculateAttributeJob : IJobEntity
        {
            // 只处理有脏标记的 ASC
            void Execute(
                ref DynamicBuffer<BAttribute> attributes,
                in DynamicBuffer<BActiveModifier> modifiers,
                EnabledRefRW<CAttributeDirty> dirty)
            {
                for (int i = 0; i < attributes.Length; i++)
                {
                    var attr = attributes[i];
                    if (!attr.Dirty) continue;

                    // 重新计算 CurrentValue
                    float additive = 0f;
                    float multiplicative = 1f;
                    float overrideValue = float.NaN;

                    for (int j = 0; j < modifiers.Length; j++)
                    {
                        var mod = modifiers[j];
                        if (mod.AttrSetCode != attr.AttrSetCode || mod.AttrCode != attr.Code) continue;

                        switch (mod.Operation)
                        {
                            case GEOperation.Add: additive += mod.Magnitude; break;
                            case GEOperation.Multiply: multiplicative *= mod.Magnitude; break;
                            case GEOperation.Override: overrideValue = mod.Magnitude; break;
                        }
                    }

                    attr.CurrentValue = float.IsNaN(overrideValue)
                        ? (attr.BaseValue + additive) * multiplicative
                        : overrideValue;
                    attr.Dirty = false;
                    attributes[i] = attr;
                }

                // 清除脏标记（IEnableableComponent，无 Archetype 变更）
                dirty.ValueRW = false;
            }
        }
    }
}
```

```csharp
// ============================================================
// [OOP Shell] OOP 层消费 ECS 事件（在 OOP Shell 中轮询）
// 文件: Assets/GAS/Runtime/Shell/GASEventDispatcher.cs
// ============================================================
// 这是 OOP Shell 的核心职责：将 ECS 事件队列转发给 OOP 订阅者。
// 注意：这个类运行在主线程，不在 ECS System 中，不影响 Burst。

using System;
using System.Collections.Generic;
using Unity.Entities;

namespace GAS.Runtime.Shell
{
    /// <summary>
    /// OOP Shell 的事件分发器。
    /// 在每帧末尾（LateUpdate 或 PresentationSystemGroup 后）消费 ECS 事件队列，
    /// 转发给注册的 OOP 回调。
    /// </summary>
    public class GASEventDispatcher
    {
        private readonly Dictionary<Entity, Action<AbilityActivationResult>> _activateCallbacks = new();
        private readonly Dictionary<Entity, Action<int, float, float>> _attrChangedCallbacks = new();

        // 由 GASBootstrap 在每帧调用
        public void Dispatch(EntityManager em, Entity eventSingleton)
        {
            // 消费 Ability 激活结果事件
            var activationResults = em.GetBuffer<BAbilityActivationResult>(eventSingleton);
            for (int i = 0; i < activationResults.Length; i++)
            {
                var evt = activationResults[i];
                if (_activateCallbacks.TryGetValue(evt.AbilityEntity, out var cb))
                    cb?.Invoke(evt.Result);
            }
            activationResults.Clear();

            // 消费属性变化事件
            var attrEvents = em.GetBuffer<BAttributeChangedEvent>(eventSingleton);
            for (int i = 0; i < attrEvents.Length; i++)
            {
                var evt = attrEvents[i];
                if (_attrChangedCallbacks.TryGetValue(evt.AscEntity, out var cb))
                    cb?.Invoke(evt.AttrCode, evt.OldValue, evt.NewValue);
            }
            attrEvents.Clear();
        }

        public void RegisterOnActivateResult(Entity abilityEntity, Action<AbilityActivationResult> cb)
            => _activateCallbacks[abilityEntity] = cb;

        public void UnregisterOnActivateResult(Entity abilityEntity)
            => _activateCallbacks.Remove(abilityEntity);
    }
}
```

### 3.5 OOP Shell 重构：轻量句柄，边界清晰


**重构方向**：`UnitGASFacade` 只是一个轻量句柄，只持有 `Entity`，所有操作都是向 ECS 写入命令，不驱动任何逻辑。

```csharp
// ============================================================
// [OOP Shell] 轻量 GAS 门面（替代 AbilitySystemCell）
// 文件: Assets/GAS/Runtime/Shell/UnitGASFacade.cs
// ============================================================
// 设计原则：
// 1. 只持有 Entity，不持有任何运行时状态
// 2. 所有"写"操作都是向 ECS 写入命令组件（Command Pattern）
// 3. 所有"读"操作都是从 ECS 读取数据（只读，不缓存）
// 4. 事件订阅通过 GASEventDispatcher，不直接持有回调字典

using Unity.Entities;
using UnityEngine;

namespace GAS.Runtime.Shell
{
    /// <summary>
    /// GAS 的 OOP 门面。
    /// 职责：作为 ECS Entity 的轻量句柄，供 UI、动画、网络等 OOP 模块使用。
    /// 禁止：持有运行时状态，驱动 ECS 逻辑，缓存 ECS 数据。
    /// </summary>
    public readonly struct UnitGASFacade
    {
        public readonly Entity AscEntity;
        private static EntityManager EM => GASWorld.EntityManager;

        public UnitGASFacade(Entity ascEntity) => AscEntity = ascEntity;

        public bool IsValid => AscEntity != Entity.Null && EM.Exists(AscEntity);

        // ---- 命令写入（不驱动逻辑，只写命令）----

        /// <summary>
        /// 请求激活 Ability。
        /// 实际激活由 STryActivateAbility System 在下一个 ECS Tick 处理。
        /// </summary>
        public void RequestActivateAbility(int abilityCode, in CAbilityParam param = default)
        {
            if (!IsValid) return;
            var abilityEntity = FindAbilityEntity(abilityCode);
            if (abilityEntity == Entity.Null) return;

            EM.SetComponentData(abilityEntity, param);
            EM.AddComponent<CAbilityActivateCmd>(abilityEntity);
        }

        public void RequestEndAbility(int abilityCode)
        {
            if (!IsValid) return;
            var abilityEntity = FindAbilityEntity(abilityCode);
            if (abilityEntity != Entity.Null)
                EM.AddComponent<CAbilityEndCmd>(abilityEntity);
        }

        // ---- 状态查询（只读，不缓存）----

        /// <summary>
        /// 查询属性当前值。
        /// 注意：此方法每次调用都读取 ECS 数据，UI 层应控制调用频率。
        /// 推荐：订阅 BAttributeChangedEvent 事件，而非每帧轮询。
        /// </summary>
        public float GetAttrCurrentValue(int attrSetCode, int attrCode)
        {
            if (!IsValid) return 0f;
            var attrs = EM.GetBuffer<BAttribute>(AscEntity, true);
            for (int i = 0; i < attrs.Length; i++)
            {
                if (attrs[i].AttrSetCode == attrSetCode && attrs[i].Code == attrCode)
                    return attrs[i].CurrentValue;
            }
            return 0f;
        }

        public bool HasTag(int tagId)
        {
            if (!IsValid) return false;
            return TagHelper.HasTag(EM.GetBuffer<BFixedTag>(AscEntity, true), tagId)
                || TagHelper.HasTag(EM.GetBuffer<BTemporaryTag>(AscEntity, true), tagId);
        }

        // ---- GE 施加（命令写入）----

        /// <summary>
        /// 对目标施加 GameplayEffect。
        /// 通过写入 CGEApplyCmd 命令，由 SGEffect 系统处理。
        /// </summary>
        public void ApplyGameplayEffect(int geCode, UnitGASFacade target)
        {
            if (!IsValid || !target.IsValid) return;
            var cmdEntity = EM.CreateEntity();
            EM.AddComponentData(cmdEntity, new CGEApplyCmd
            {
                GeCode = geCode,
                Source = AscEntity,
                Target = target.AscEntity
            });
        }

        // ---- 内部工具 ----

        private Entity FindAbilityEntity(int abilityCode)
        {
            var abilities = EM.GetBuffer<BAbility>(AscEntity, true);
            for (int i = 0; i < abilities.Length; i++)
            {
                var abilityEntity = abilities[i].Ability;
                if (EM.GetComponentData<CAbilityDef>(abilityEntity).Code == abilityCode)
                    return abilityEntity;
            }
            return Entity.Null;
        }
    }
}
```

```csharp
// ============================================================
// [ECS核心] GE 施加系统（Burst 编译）
// 文件: Assets/GAS/Runtime/System/GameplayEffect/SApplyGECmd.cs
// ============================================================

using Unity.Burst;
using Unity.Entities;
using Unity.Collections;
using GAS.Runtime.Data;

namespace GAS.Runtime
{
    [UpdateInGroup(typeof(SGEffectCreate))]
    [BurstCompile]
    public partial struct SApplyGECmd : ISystem
    {
        [BurstCompile]
        public void OnCreate(ref SystemState state)
        {
            state.RequireForUpdate<CGEApplyCmd>();
        }

        [BurstCompile]
        public void OnUpdate(ref SystemState state)
        {
            var ecb = new EntityCommandBuffer(Allocator.Temp);
            var registry = SystemAPI.GetSingleton<GASConfigRegistry>();
            var tagLookup = SystemAPI.GetBufferLookup<BFixedTag>(true);
            var geLookup = SystemAPI.GetBufferLookup<BGameplayEffect>();
            var timer = SystemAPI.GetSingleton<GlobalTimer>();

            foreach (var (cmd, cmdEntity) in SystemAPI
                .Query<RefRO<CGEApplyCmd>>()
                .WithEntityAccess())
            {
                var geCode = cmd.ValueRO.GeCode;
                ref var geDef = ref FindGEDef(ref registry.EffectDefs.Value, geCode);

                // 检查 ApplicationRequiredTags
                if (!CheckApplicationTags(cmd.ValueRO.Target, ref geDef, tagLookup))
                {
                    ecb.DestroyEntity(cmdEntity);
                    continue;
                }

                // 将 GE 实例写入目标 ASC 的 Buffer
                var geBuffer = geLookup[cmd.ValueRO.Target];
                geBuffer.Add(new BGameplayEffect
                {
                    GeCode = geCode,
                    SourceAsc = cmd.ValueRO.Source,
                    ActivateFrame = timer.Frame,
                    StackCount = 1,
                    Flags = 1 // Active
                });

                // 标记目标 ASC 属性为脏（触发重新计算）
                ecb.SetComponentEnabled<CAttributeDirty>(cmd.ValueRO.Target, true);

                // 销毁命令 Entity
                ecb.DestroyEntity(cmdEntity);
            }

            ecb.Playback(state.EntityManager);
            ecb.Dispose();
        }

        [BurstCompile]
        private static ref GameplayEffectDefBlob FindGEDef(
            ref BlobArray<GameplayEffectDefBlob> defs, int code)
        {
            for (int i = 0; i < defs.Length; i++)
                if (defs[i].Code == code) return ref defs[i];
            // 返回第一个作为 fallback（实际应有错误处理）
            return ref defs[0];
        }

        [BurstCompile]
        private static bool CheckApplicationTags(
            Entity target,
            ref GameplayEffectDefBlob geDef,
            in BufferLookup<BFixedTag> tagLookup)
        {
            if (!tagLookup.HasBuffer(target)) return true;
            var tags = tagLookup[target];
            for (int i = 0; i < geDef.ApplicationRequiredTags.Length; i++)
            {
                if (!TagHelper.HasTag(tags, geDef.ApplicationRequiredTags[i]))
                    return false;
            }
            return true;
        }
    }
}
```

## 五、Luban 配置链路的进一步解放

重构后，Luban 的职责应该扩展为：

```
Excel (策划编辑)
    ↓ Luban 生成

    ↓ 运行时
BlobAssetReference<T> (零拷贝，Burst可访问)
```

这样，Luban 不再只是"生成常量和JSON"，而是**直接参与 ECS 数据结构的构建**，真正成为 ECS 数据管线的一部分。
