# 术语表

| 术语 | 含义 |
|---|---|
| ASC | Ability System Component，在 EX-GAS 2.0 中表达为 ECS entity + components/buffers |
| Application Shell Layer | 应用壳层，UI、输入、AI、网络、场景、Demo runner、真实资源或无头 log marker 所在层 |
| Runtime Boundary Layer | 运行时边界层，CommandGateway、ReadModel、PresentationOutboxBridge、DiagnosticsSink、ReplaySink 所在层 |
| GAS Runtime Core Layer | GAS 运行时核心层，ASC、Ability、GameplayEffect、Attribute、Tag、Target、EffectCommand、Spec/Delta/Fact 语义链、ActiveEffectStore、GameplayFact 所在层 |
| Definition & Generation Layer | 定义与生成层，Luban source、schema、generated id、static lookup、Blob/Bake plan、validation summary 所在层 |
| Definition Catalog | Runtime Core 只读静态定义目录，目标承载为 `GASDefinitionCatalogBlob` + `GASDefinitionCatalogComponent`；不是 managed registry |
| Generated Runtime Glue | SourceGenerator 生成的 Runtime 静态纯函数集合，如 `GASGeneratedRuntimeDefinitionResolver`、Requirement/Magnitude evaluator、TargetRule table；把 definition index/range 转为 frame-local record，不是 service 或 lifecycle system |
| Generated Runtime Lifecycle | 禁止作为目标态的 generated runtime 执行管线形态；指 Runtime-visible generated artifact 生成 `ISystem`、system registration、`OnUpdate`、hidden query、hidden ECB、NativeContainer owner 或 `EntityManager` 写入 |
| Runtime-visible Generated Artifact | 编译进 Runtime assembly、可被 Runtime Core 引用的 generated 文件；默认只能包含 id、Blob schema、lookup、record、static pure glue，不得拥有 system lifecycle、query、ECB、EntityManager 或 NativeContainer |
| MigrationProofOnly / MigrationProofOnly Generated Artifact | 迁移期保留的非目标态 generated 或 runtime artifact；必须有明确用途、规模限制、validation 标记、违反规则清单和移除任务，不能被当成完成证明 |
| Catalog Bootstrap Owner | 负责在 Baking / Bootstrap / initialization 阶段构建并安装 `GASDefinitionCatalogBlob` 的 owner；同时负责 runtime-created Blob dispose，不属于 Runtime Core hot path |
| SourceGenerator Ownership Gate | 生成链验收门禁；扫描 runtime-visible generated artifact 是否越权拥有 lifecycle system、system registration、query、ECB、EntityManager、NativeContainer 或 hot path `BlobBuilder` |
| Definition Plane | 旧口径；已吸收到 Definition & Generation Layer |
| Simulation Plane | 旧口径；已吸收到 GAS Runtime Core Layer |
| Observation Plane | 旧口径；已拆入 Runtime Boundary Layer 的 ReadModel / Outbox / Diagnostics / Replay 职责 |
| EffectCommand | 未来 Effect 施加意图流 |
| InstantEffectSpec | simple instant GE 的一次性计算输入 |
| AttributeDelta | 属性变更数据，不等同表现事件 |
| TypedSimulationFact | 供业务 reaction 消费的 typed facts |
| Runtime Core Debugger | 运行健康诊断流，记录 counters、buffer pressure、timing |
| Headless | 无画面、无真实资源接入，但表现/Cue 逻辑仍要输出 marker |
| CommandGateway | 运行时边界层写入入口，把应用壳层意图转换为 request entity、command buffer 或等价 command data |
| ReadModel | 运行时边界层只读镜像，不暴露可写 ECS 句柄 |
| OutboxBridge | 运行时边界层表现桥，全称 PresentationOutboxBridge；消费 Core facts 并输出 UI/Cue/VFX/SFX/FloatingText marker |
| DiagnosticsSink | 运行时边界层诊断导出，不参与 gameplay routing |
| Battle Runtime Adapter | 应用壳层业务 Demo 到 Runtime Boundary / Runtime Core 的单一 seam；对外表达 battle runtime 动作，对内分类承载 RuntimeHost、CatalogSession、BattleEntityLifecycle、ObservationGateway，不是 OOP gameplay 中间层 |
| RuntimeHost | Battle Runtime Adapter 内部 owner，负责 GAS runtime init/shutdown、固定步 tick 和物理 SystemGroup 推进 |
| CatalogSession | Battle Runtime Adapter 内部 owner，负责 generated catalog install、revision、runtime-created Blob dispose |
| BattleEntityLifecycle | Battle Runtime Adapter 内部 owner，负责本场 driver、ASC unit handle、granted ability / active effect cleanup 的 lifecycle 入口 |
| ObservationGateway | Battle Runtime Adapter 内部 owner，负责 observation reset、structured snapshot、official diff capture、diagnostics export |
| ValidationEvidence | headless runner、scene runner、Profiler pass、official diff pass 共享的机器可读验收事实模型；字符串 summary、Mermaid 图和日志是它的导出格式 |
| Unity Entities 机制校准 | 将 GAS ECS 目标态落到 Unity Entities 1.4.6 的 SystemGroup、ISystem、Job、ECB、Enableable、DynamicBuffer、Blob、Baker、Query filter 等官方机制 |
| Unity Entities 使用规范 | 将 Unity 官方 ECS 使用规则转译为 Runtime Core 编码规范、规则编号、检查表和禁止事项 |
| Physical SystemGroup | Runtime Core 中表达同步、结构变化、投影等物理执行域的 Unity `ComponentSystemGroup`；不是业务目录 |
| Kernel Lane | Runtime Core 中表达业务数据流职责的 lane system / job chain；默认不升格为 `ComponentSystemGroup` |
| Structural Commit Phase | Runtime Core 中唯一允许集中执行 ECB playback / entity create / destroy / add / remove 的结构变化物理执行域 |
| CoreReactionFact | Runtime Core 内部 reaction 使用的 typed fact，不进入 Presentation / Replay 主通道 |
| BoundaryObservationFact | Runtime Boundary 用于 ReadModel / Presentation / Replay / Debugger 的观察事实 |
| Stable Archetype | 通过 enableable、slot、buffer 和状态值表达高频变化，避免频繁 add / remove component 的稳定 ECS 布局 |
