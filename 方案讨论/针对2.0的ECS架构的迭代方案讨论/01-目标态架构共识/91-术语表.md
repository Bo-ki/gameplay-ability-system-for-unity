# 术语表

| 术语 | 含义 |
|---|---|
| ASC | Ability System Component，在 EX-GAS 2.0 中表达为 ECS entity + components/buffers |
| ECS 权威状态 | 跨帧存在并决定 gameplay 结果的 Runtime Core 数据，只能由 ECS System / Job 写入 |
| frame-local record | 本帧 command、target、spec、delta、fact 等中间计算记录；不默认创建 entity，不跨帧持久化 |
| Boundary 投影 | 从 Runtime Core typed fact / diagnostics 派生出的 read model、presentation outbox、replay、debugger、structured log |
| Definition 输入 | Luban / SourceGenerator / Blob / generated lookup / static pure glue 提供的不可变配置输入 |
| Application Shell Layer | 应用壳层，UI、输入、AI、网络、场景、Demo runner、真实资源或无头 log marker 所在层 |
| Runtime Boundary Layer | 运行时边界层，CommandPort、ReadModel、PresentationOutboxBridge、DiagnosticsSink、ReplaySink 所在层 |
| GAS Runtime Core Layer | GAS 运行时核心层，ASC、Ability、GameplayEffect、Attribute、Tag、Target、EffectCommand、Spec/Delta/Fact 语义链、ActiveEffectStore、GameplayFact 所在层 |
| Definition & Generation Layer | 定义与生成层，Luban source、schema、generated id、static lookup、Blob/Bake plan、validation summary 所在层 |
| Definition Catalog | Runtime Core 只读静态定义目录，目标承载为 `GASDefinitionCatalogBlob` + `GASDefinitionCatalogComponent`；不是 managed registry |
| Generated Runtime Glue | SourceGenerator 生成的 Runtime 静态纯函数集合，如 `GASGeneratedRuntimeDefinitionResolver`、Requirement/Magnitude evaluator、TargetRule table；把 definition index/range 转为 frame-local record，不是 service 或 lifecycle system |
| Generated Runtime Lifecycle | 禁止作为目标态的 generated runtime 执行管线形态；指 Runtime-visible generated artifact 生成 `ISystem`、system registration、`OnUpdate`、hidden query、hidden ECB、NativeContainer owner 或 `EntityManager` 写入 |
| Runtime-visible Generated Artifact | 编译进 Runtime assembly、可被 Runtime Core 引用的 generated 文件；默认只能包含 id、Blob schema、lookup、record、static pure glue，不得拥有 system lifecycle、query、ECB、EntityManager 或 NativeContainer |
| MigrationProofOnly / MigrationProofOnly Generated Artifact | 非目标态保留的 generated 或 runtime artifact；必须有明确用途、规模限制、validation 标记、违反规则清单和移除任务，不能被当成完成证明 |
| Catalog Bootstrap Owner | 负责在 Baking / Bootstrap / initialization 阶段构建并安装 `GASDefinitionCatalogBlob` 的 owner；同时负责 runtime-created Blob dispose，不属于 Runtime Core hot path |
| SourceGenerator Ownership Gate | 生成链验收门禁；扫描 runtime-visible generated artifact 是否越权拥有 lifecycle system、system registration、query、ECB、EntityManager、NativeContainer 或 hot path `BlobBuilder` |
| Definition Plane | 旧口径；已吸收到 Definition & Generation Layer |
| Simulation Plane | 旧口径；已吸收到 GAS Runtime Core Layer |
| Observation Plane | 旧口径；已拆入 Runtime Boundary Layer 的 ReadModel / Outbox / Diagnostics / Replay 职责 |
| EffectCommand | 未来 Effect 施加意图流 |
| InstantEffectSpec | simple instant GE 的一次性计算输入 |
| AttributeDelta | 属性变更数据，不等同表现事件 |
| TypedSimulationFact | 供业务 reaction 消费的 typed facts |
| Runtime Core Debugger | 运行健康诊断流，记录 counters、buffer pressure、timing |
| Headless | 无画面、无真实资源接入，但表现/Cue 逻辑仍要输出 marker |
| CommandPort | 运行时边界层写入入口，把应用壳层意图转换为 request entity、command buffer 或等价 command data；公开方法以 `Request*` 表达异步命令写入 |
| ReadModel | 运行时边界层只读镜像，不暴露可写 ECS 句柄 |
| OutboxBridge | 运行时边界层表现桥，全称 PresentationOutboxBridge；消费 Core facts 并输出 UI/Cue/VFX/SFX/FloatingText marker |
| DiagnosticsSink | 运行时边界层诊断导出，不参与 gameplay routing |
| Battle Runtime Adapter | 应用壳层业务 Demo 到 Runtime Boundary / Runtime Core 的单一 seam；对外表达 battle runtime 动作，对内分类承载 RuntimeHost、CatalogSession、BattleEntityLifecycle、ObservationGateway，不是 OOP gameplay 中间层 |
| RuntimeHost | Battle Runtime Adapter 内部 owner，负责 GAS runtime init/shutdown、固定步 tick 和物理 SystemGroup 推进 |
| CatalogSession | Battle Runtime Adapter 内部 owner，负责 generated catalog install、revision、runtime-created Blob dispose |
| BattleEntityLifecycle | Battle Runtime Adapter 内部 owner，负责本场 driver、ASC unit handle、granted ability / active effect cleanup 的 lifecycle 入口 |
| ObservationGateway | Battle Runtime Adapter 内部 owner，负责 observation reset、structured snapshot、official diff capture、diagnostics export |
| ValidationEvidence | headless runner、scene runner、Profiler pass、official diff pass 共享的机器可读验收模型；字符串 summary、Mermaid 图和日志是它的导出格式 |
| Unity Entities 机制校准 | 将 GAS ECS 目标态落到 Unity Entities 1.4.6 的 SystemGroup、ISystem、Job、ECB、Enableable、DynamicBuffer、Blob、Baker、Query filter 等官方机制 |
| Unity Entities 使用规范 | 将 Unity 官方 ECS 使用规则转译为 Runtime Core 编码规范、规则编号、检查表和禁止事项 |
| DOTS Official Review Gate | 新 Runtime Core 任务或 Runtime Semantic Extension 进入实现前必须通过的官方规范复核门槛；包括 lane、store、carrier、phase、query contract、allocator、structural policy、Burst / managed 边界、官方规则编号、重选型触发条件和 proof-only 退出条件 |
| Performance Redline | 目标态不可接受的 DOTS 性能/职责违规，如 managed hot path、entity churn、分散结构变化、隐藏 generated lifecycle、全局 singleton fan-in、无证明 random lookup 写和 Debugger 托管日志污染 |
| Ability Package / Effect Package | Editor / Authoring 层的业务能力包，用来聚合一个业务技能、Buff、光环或 Cue 相关的 Ability、GameplayEffect、Tag、Attribute、Cue 和 validation profile；不是 Runtime Core entity 或 managed runtime object |
| Planner Configuration Capability | 策划配置能力，指策划用业务模板和业务能力包创建、修改、校验、预览、发布 GAS 内容的完整能力；包括影响分析、Runtime trace preview、平衡预览和发布校验快照 |
| Business Template Catalog | 业务模板目录，描述可创建的技能、Buff、光环、Cue、Scenario 等模板及其字段、默认值、引用选择源、row projection 和 validation rules；由 Luban schema / SourceGenerator metadata / Editor Binding 驱动 |
| Business Package Change Set | 业务包变更集，一次配置修改的评审单元，包含 row diff、引用变更、影响分析、hash 输入、Runtime trace preview id 和 review gate summary |
| Business Authoring Session | Editor 配置链中的一次业务编辑会话，承载模板参数、引用选择、row diff、validation snapshot 和 Runtime trace preview；保存后必须投影为 Luban rows |
| Definition Draft Graph | Editor-only 的配置草稿图，表达 Ability / GE / Tag / Cue / Attribute 的跨表引用关系；不得进入 Runtime Core hot path |
| Definition Row Projection | 将业务能力包 / draft graph 写回 Luban row 的过程，是 Editor 配置链到 Luban 权威配置链的唯一合法桥接 |
| Config Graph Validation | 对业务包跨表引用、schema、DOTS carrier、buffer capacity hint、SourceGenerator ownership gate 和 Runtime trace 的配置图校验 |
| Config Reference Graph | 配置引用图，从 normalized rows / generated metadata 构建 Ability、GE、Modifier、Requirement、Cue、Tag、Attribute、Unit、Scenario 和 generated artifact 的正反向引用关系 |
| Config Review Gate | 配置评审门禁，对 Business Package Change Set 执行 schema、引用、DOTS carrier、SourceGenerator ownership、Runtime trace、impact 和 scenario expectation 校验 |
| Impact Analysis | 影响分析，配置变更前后追踪受影响的 Ability Package、Effect Package、Unit、Scenario、Scale profile、validation expectation 和 generated artifact |
| Runtime Trace Preview | Runtime 轨迹预览，Editor / CI 根据 row projection、generated catalog metadata 和 pure glue 推导业务配置将如何进入 `AbilityActivationPlanRecord`、`GECommandSeedRecord`、`ResolvedModifierRecord`、GameplayFact 和 Boundary Cue |
| Publish Validation Snapshot | 发布校验快照，业务包发布时输出的可审计诊断产物，至少包含 row diff、schema hash、content hash、validation summary、impact analysis id 和 Runtime trace preview id |
| Balance Preview | 平衡预览，按业务包聚合展示等级、消耗、冷却、公式、DOT tick、stack、overflow policy 和异常曲线的配置期预览 |
| Raw Table Advanced Mode | 高级原始表维护入口，允许框架维护者直接查看和修复 Excel/raw protocol；不得作为策划默认业务编辑路径 |
| Scenario Validation Binding | 场景校验绑定，把业务包和 Unit、Scenario、Scale profile、validation expectation 连接起来，用于 CI / headless runner 输出机器可读业务验收证据 |
| Generated Editor Binding | SourceGenerator 输出给 Editor 使用的 schema metadata、template field metadata、choice source、reference type、diagnostics code、display hint 和 raw protocol mapping |
| AutoChess Acceptance Ability Sample | AutoChess 策划配置验收样例，最小业务验收单元；包含 BusinessPackage、PlannerIntent、RowProjection、ConfigReferenceGraph、RuntimeTracePreview、ScenarioValidationBinding、BalancePreview、AcceptanceAssertions 和 ImpactAnalysis |
| Ability Addition Workflow | 新增能力业务推进流程；先按配置型能力、胶水扩展型能力、Runtime 语义型能力三档分类，再决定策划路径、程序介入层和验证范围 |
| Authoring / Generation Control Plane | Editor / CI / Definition & Generation 侧的新增能力控制面；管理业务表达、row projection、生成元数据、影响分析、Runtime Trace Preview 和发布证据，不进入 Runtime Core，也不拥有 gameplay state |
| Ability Configuration Analysis Protocol | 能力配置分析协议；对业务意图、激活、目标、效果拆解、公式、Requirement、Duration / Period / Stack、表现绑定、row projection、trace、impact 和发布证据执行的配置期分析顺序 |
| Ability Configuration Analysis Report | 能力配置分析报告；Ability Configuration Analysis Protocol 的机器可读输出，记录每一步结果、失败归因和是否触发 Generated Glue Extension / Runtime Semantic Extension |
| Definition Row Projection Plan | 业务包投影到 Luban rows 的机器可读计划，包含 rows to create/update、stable ids、raw protocol mapping、reference edges、trace shape 和 validation rules |
| GAS Official Concept Mapping | GAS 官方概念映射；把 Epic GAS 的 ASC、Ability、GameplayEffect definition/spec、AttributeSet、GameplayTag、GameplayCue 和 AbilityTask 语义映射到 Unity DOTS 目标承载，防止短编辑路径丢失业务语义 |
| AbilityLifecycleContract | Ability definition 必须输出的生命周期契约，覆盖 grant、can activate、activate、commit、cancel、block、end、failure reason 和 trace shape |
| GameplayEffectSpecShape | GameplayEffect definition 进入 Runtime 前保留的 spec 形状，包含 source/target context、level、magnitude inputs、duration、period、stack、requirement、granted state 和 cue policy |
| GameplayTagTaxonomy | GameplayTag 分类表，区分 owned、asset、activation required/blocked、cancel/block ability、application/ongoing/removal、immunity、cue route 和 gameplay event 等语义 |
| CueParameterContract | GameplayCue 的 Boundary 参数契约，包含 cue tag、cue event、source/target、effect context、magnitude snapshot、presentation binding key 和 trace id |
| AbilityTaskSemanticMapping | 将 UE AbilityTask 的异步、等待、目标收集、事件流控制语义映射到 ECS target lane、async state slot、typed fact、Boundary command 或 bounded reaction pass 的规则 |
| ASCBindingContract | Unit / Scenario / GE grant 到 Runtime ASC state 的绑定契约，描述 AttributeSet family、owned tags、granted abilities、initial active effects 和 install / cleanup policy |
| Configuration-Only Ability | 配置型能力；已有 Business Template、target rule、requirement、magnitude evaluator、Runtime lane 和 carrier，仅通过业务参数、row projection、validation snapshot 和 scenario evidence 发布，程序 0 代码 |
| Generated Glue Extension | 胶水扩展型能力；Runtime 语义和 carrier 已存在，但缺少模板字段、target rule、requirement、magnitude evaluator、Generated Editor Binding 或 validation rule，只允许扩展 SourceGenerator metadata / pure glue / Editor Binding |
| Runtime Semantic Extension | Runtime 语义型能力；需要新增 Runtime lane、store、carrier、structural policy、phase 或高规模数据选型，必须先通过 DOTS Official Review Gate |
| Impact-Scoped Validation | 影响面裁剪验证；由 Config Reference Graph / Impact Analysis 选择受影响的 scenario、scale profile 和 validation expectation，而不是默认全量或人工选择 |
| Physical SystemGroup | Runtime Core 中表达同步、结构变化、投影等物理执行域的 Unity `ComponentSystemGroup`；不是业务目录 |
| Kernel Lane | Runtime Core 中表达业务数据流职责的 lane system / job chain；默认不升格为 `ComponentSystemGroup` |
| Structural Commit Phase | Runtime Core 中唯一允许集中执行 ECB playback / entity create / destroy / add / remove 的结构变化物理执行域 |
| CoreReactionFact | Runtime Core 内部 reaction 使用的 typed fact，不进入 Presentation / Replay 主通道 |
| BoundaryObservationFact | Runtime Boundary 用于 ReadModel / Presentation / Replay / Debugger 的观察事实 |
| Bounded Reaction Pass | 允许同帧 Gameplay Fact 触发后续 GE 的显式有限轮次机制；必须声明最大 pass count、cutoff reason 和 Debugger counters |
| Stable Archetype | 通过 enableable、slot、buffer 和状态值表达高频变化，避免频繁 add / remove component 的稳定 ECS 布局 |
