# EX-GAS Runtime v1 术语表

| 术语 | 定义 |
|---|---|
| ASC | Ability System Component 的 DOTS 聚合根 Entity；不是单个 C# Component 类型 |
| SimulationEpoch | 一次 World/Session 生命周期身份，使旧 handle/command 在新世界失效 |
| SimulationTick | GAS 权威固定步序号；一个 RenderFrame 可以有 0..N 个 tick |
| BattleInstanceId | 同一 GAS Session 内一场独立战局的稳定身份；单实例终局不等于 Session 终止 |
| Session Ready | EndFixed创建 Pending batch 后，由下一 Kernel SpawnFinalize maintenance lane全量验证并整批发布 handle；该 maintenance update不计 gameplay Tick |
| AscRegistrySlot | Session-owned non-compacting ASC registry entry；Pending不可寻址，SpawnFinalize整批置 Ready，Gather据此建 tick-local lookup |
| RenderFrame | Unity 渲染/主循环帧，不用于 duration/period/cooldown 权威计时 |
| GasFixedTickSystemGroup | 主 FixedStep 中位于 Physics 后的唯一 GAS 物理执行域 |
| GasTickKernelSystem | 单个 tick 的 query、scratch、Job DAG、target mutation 和最终 dependency owner |
| Logical Stage | Kernel 内命名的 Gather/Activation/FanIn/Apply/Stabilize/Fact 等职责，不是 SystemGroup |
| Tick Scratch | 由 Kernel 使用 WorldUpdateAllocator 持有的本 tick 临时数据；旧称 FrameArena 的路线被删除 |
| OwnerPlanBuild | 在 scratch 中按 ASC canonical read-your-writes模拟 CommitPlan，不写权威状态的阶段 |
| WholeTickInfrastructureAdmission | 权威写前按生成上界预留 scratch/slab/payload/pending/fact/outbox；失败使本 tick 权威零写 |
| SessionFaultLatch | fault 时的固定大小控制证据；DAG 内从 Empty→Detected并冻结 sealed subset，outer FaultClose 与 CommandPort accept 在同一 gate 线性化后终结为 IngressClosed，冻结 close 前 accepted-outstanding first/last/count/hash，不写逐 request Boundary fact |
| SessionIngressGate | Runtime Boundary 中 CommandPort accept 与 fault close 的唯一线性化 owner；分配 RequestSequence并拥有 BoundaryIngressJournal，close 前 accepted 必被 FaultId 覆盖，close 后同步拒绝 |
| PlanExpandScratchEnvelopeToken | Gather 以 sealed/due count 与 Catalog bake maxima checked 计算的 pre-admission scratch envelope；在 OwnerPlanBuild/TargetResolve 写前 provision，逻辑失败由后续唯一 AdmissionResult提升 |
| AscOwnerCommandWave | source ASC 单 writer提交已 admission 的 CommitPlan 的 mutation wave |
| AscTargetStateWave | target ASC 单 writer处理 application/stack/Attribute/Tag/Death 的 mutation wave |
| Target-owned Mutation Lane | 一个 ASC 在一个 target state wave 内唯一的逻辑写入序列；不同 ASC 可并行 |
| Canonical Key | 仅由稳定语义字段组成、决定 command/fact 顺序的全序键 |
| SemanticPhaseOrdinal | Catalog/schema-hashed 语义阶段序号；不是 Job、Profiler 或 worker lane |
| GasAscIdentity | Epoch、稳定 ASC ID 与 Generation 构成的 Core 身份 |
| GasActorBinding | 稳定逻辑 Owner 与可替换 AvatarEntity/StableAvatarId/BindingGeneration 的 Core 绑定 |
| Generational Handle | `Epoch + OwnerAscHandle(AscStableId, AscGeneration) + SlotIndex + SlotGeneration`，并由领域强类型区分池 |
| GrantedAbilitySlot | Ability Definition 授予某 ASC 后的长期实例槽 |
| AbilityActivationSlot | 一次独立 Ability 激活的状态、因果和子 Continuation owner |
| AbilityContinuationSlot | 可独立等待、唤醒、结束或取消的异步状态槽；一个 Activation 可有多个 |
| AbilitySubscriptionSlot | 对本地或外部 ASC 事件/Tag 的持久或一次性订阅记录 |
| CostMutationContract | 生成期封闭的 owner-local cost 预检/变更契约；Commit 直接写同一 ASC 的 AttributeValueSlot权威 |
| CooldownGateSlot | source ASC-owned、独立于 Activation/ActiveEffect 的冷却权威槽；持续到 EndTick/明确 removal policy |
| Wait Registration Handshake | 跨 ASC `PendingRegistration -> Ack/Completion` 协议，配合两端 Generation避免 lost wakeup |
| OwnedContributionRanges | Activation 真正拥有并在 End 时清理的 Tag/Block/Cue/Continuation 范围 |
| EmittedApplicationRefs | Activation 已发 Effect application 的审计引用；默认不拥有其清理权 |
| EffectApplicationSpec | 应用前冻结/持久化的 Effect 值对象；携带 Context、SetByCaller 与 capture，不等于 ActiveEffect |
| EffectApplicationId | 一次 Effect 应用尝试身份；Instant 与 stack merge 也必须存在 |
| ApplicationOutcome | target线性化点产生的 Applied/Rejected/BlockedByImmunity/Overflow 等 typed结果及 provenance |
| ActiveEffectSlot | 成功应用后在目标 ASC 上存活的 Duration/Infinite Effect 槽 |
| StackPayloadPolicy | 聚合 stack 如何保留首次、最新或逐层 Application/Capture payload 的明确策略 |
| Committed-work-wins | source后续死亡/取消不撤回已 Commit operation；target仍按当前 policy独立接受或拒绝 |
| TargetLifePolicy | application 对 Alive/Dead/Any life state 的显式接受规则 |
| PeriodDue | tick-start 已到期并在 DueTick 同 tick处理的 scheduled work；不同于 post-apply 动态 child |
| ContributorId | Aggregator 中可精确选择、忽略和撤销的一项 modifier 来源身份 |
| DeathTransitionId | 首次 Health crossing冻结的死亡身份，关联 killer、unclamped/overkill与 causality |
| Tombstone | 对象已退出 gameplay 但仍等待子记录、队列或 Boundary 交接，尚未进入 free-list 的槽状态 |
| AttributeLayout | Session 内不可变的 AttributeDefinitionId→dense index 映射 |
| AttributeValueSlot | 固定布局中的 Base、Current、Revision 属性值 |
| TagCountSlot | Catalog index 对应的 ExactCount 与 InclusiveCount；Tag bitset 仅为派生缓存 |
| CaptureProjectionContract | 捕获允许读取的 ValueView、输入绑定时机与 Lifetime 的闭世界生成契约 |
| ScalarSnapshot | 在全部评估输入冻结且查询面不会升级时保存的标量捕获 |
| AggregatorSnapshot | 保存 Base、稳定有序 contribution、qualifier/provenance 的规范化捕获 |
| LiveCaptureBinding | 以 source ASC/Attribute/revision/dependent effect 建立的实时依赖 |
| PhaseSample | 某 phase 的一次冻结读取，不具有 Live Capture 的后续依赖语义 |
| DirectEffectProgram | 生成期闭合、完全展开、有限且静态有界的 same-tick Effect DAG |
| Stabilization | 单目标内让 Tag、ongoing requirement、inhibition、contribution 和 aggregator 达到固定点 |
| Stable-state Deferred Reaction | v1 公开 reaction 在 emit tick 不重入、冻结 payload 后最早下一 tick 投递的时序 |
| CoreReactionRecord | Core 内路由到下一 tick pending work 的权威反应记录 |
| BoundaryFactBuffer | scoped cleanup outbox；ASC fact 位于所属 ASC，BattleInstance/Session fact 位于唯一 Session，同一 fact 只存一处 |
| BoundaryEventId | `(Epoch, PhysicalOwnerKind/Id/Generation, OwnerSequence)` 复合 Boundary 交付/去重身份；不是裸 owner-local 序号 |
| BoundaryFactPlane | 与 identity ScopeKind 正交的 `Gameplay/TeardownAudit` 结果平面；只决定 BattleHash/audit inclusion，不决定 outbox owner |
| CueLifecycleKey | `Epoch + ActiveEffectHandle + ActiveCycleOrdinal + CueDefinitionOrdinal`，配对一次 active cycle |
| CueInstanceKey | Cue lifecycle identity 的历史称谓；v1 正文使用 CueLifecycleKey，不能与 BoundaryEventId复用 |
| GasBoundaryDrainSystem | fixed catch-up 后唯一将 ECS outbox 复制为 managed immutable batch 的 owner |
| BoundaryBatch | 已脱离 ECS、供所有观察消费者只读的不可变事实批次 |
| Managed Boundary Staging | 在清 ECS outbox前以 BatchId/physical owner/InFlightWatermark幂等取得事实所有权的托管接管层 |
| BoundaryDrainState.Accepted | cleanup shell 的 frozen range 已被 staging 接管且无 late tail，可以由下一 Kernel prepass或 shutdown teardown移除的状态 |
| BattleOutcomeSnapshot | `FactPlane=Gameplay` facts完成 staging接管后冻结的 winner、终局状态与 BattleHash |
| TeardownAudit Plane | 终局后用于 Cue remove、shell清理和审计的事实平面；交付但不改变 BattleHash，物理路由仍按 Asc/Battle/Session ScopeKind |
| ReadModelSnapshot | Boundary 面向 Shell 的版本化只读状态投影，不是 live ECS facade |
| CausalityId | 排序、追踪和环检测身份；不承担预测确认/拒绝/回滚 |
| Definition Catalog | Session 内不可变 Blob 定义目录及预解析索引/range |
| Generated Runtime Glue | 生成的静态纯 lookup/evaluator/record builder，不含 Runtime lifecycle |
| ScaleProfile | 指定 ASC/Attribute/Tag/Effect/command/outbox 规模及预算的可验证性能场景 |
| Runtime Boundary | CommandPort、Snapshot/Observation/Diagnostics 能力和单 Drain 所在层，不拥有 gameplay 决策 |
| Application Shell | 输入、AI、场景、UI、Demo/Headless runner 与业务资源所在层 |
| Prediction | 客户端预测副作用的 accept/reject/rollback/catch-up 机制；明确不属于 v1 |
