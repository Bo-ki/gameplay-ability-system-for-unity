## Provenance 与日志门

`Run-RuntimeV1ConformanceTests.ps1` 为 EditMode、PlayMode 生成独立 provenance sidecar，并汇总为 evidence JSON；它记录 HEAD、tracked/untracked dirty fingerprint、Unity 路径、精确筛选器、退出码、结果与日志 SHA-256。R0 已修复中文 untracked 路径被 Git 八进制转义后无法计算 blob hash 的问题。日志健康门额外拒绝 NUnit XML 可能漏报的 Job/native-container 异常、泄漏、`JobTempAlloc` 与 fatal error。

旧 `Run-StackingRuntimeTests.ps1` 已退役并硬失败，不再生成或冒充 Stacking 证据。Unity 许可证握手提示不属于 gameplay/log-health failure；测试结论以 NUnit XML、精确 TestId 对账和日志健康门三者共同判定。

以下可移植性限制只指历史 RuntimeV1 conformance aggregate：N0/N1/N2-1A 结果只保留为历史支撑，不得冒充当前 dirty fingerprint 的最终快照。本机两份历史 N2 aggregate 可重算，但 artifact 目录被忽略、路径绝对化、fresh clone 无 resolver，且 aggregate 未绑定 provenance 文件 hash；运行前 manifest `7f5eee...` 与回填后的 `e9b601...` 还是两代。新的 E0/D0-M1 机器证据同样不是 release exit 授权，但不应与该历史 resolver 缺口混为同一格式问题。
