## 当前最新索引

最新代码小闭环：AM5 CEffectCleanup execution plan shell 第一刀已接入。`CEffectCleanup.RequestedCleanupWorkFlags` 把 cleanup requested work plan 写入 cleanup shell；`ActiveEffectStore.CreateCleanupWorkFlags` 统一构造 owner-local slot、legacy target buffer、runtime modifier、granted tag、granted ability、duration runtime 与 entity destroy 子工作计划；`EffectRuntimeUtility.MarkEffectForRemoval` 与 `SAscDestroyRequest` 写 shell 时同步写 plan。`CleanupActiveEffect` 通过 `ResolveRequestedCleanupWorkFlags` 优先消费 shell plan，并用 `HasCleanupWork` gate granted ability / modifier / tag / target buffer / duration runtime / final destroy 子步骤。本轮把 cleanup execution 的 requested work plan 推进到数据面，但 cleanup/finalize execution 主体仍在主线程 EntityManager / ECB 语义阶段。

## 最近轮次摘要

### AM5 CEffectCleanup execution plan shell 第一刀（2026-05-26）

**产出 / 发现**：
1. `CEffectCleanup` 新增 `RequestedCleanupWorkFlags`，cleanup shell 开始承载 requested cleanup work plan。
2. `ActiveEffectStore.CreateCleanupWorkFlags` 成为 cleanup work plan 统一构造入口，覆盖 owner-local slot、legacy target buffer、runtime modifier、granted tag、granted ability、duration runtime 与 entity destroy。
3. `EffectRuntimeUtility.MarkEffectForRemoval` 在写 cleanup shell 前后同步 pending-remove / duration mirror，再把 resolved plan 写入 `CEffectCleanup`。
4. `SAscDestroyRequest` 直接写 cleanup shell 的 ASC destroy 路径补齐 `RequestedCleanupWorkFlags`。
5. `CleanupActiveEffect` 通过 `ResolveRequestedCleanupWorkFlags` 优先读取 shell plan，shell plan 为空时 fallback 到 `ActiveEffectStore.CreateCleanupWorkFlags`；实际 cleanup 子步骤统一通过 `HasCleanupWork` gate。
6. 新增 `ActiveEffectStoreTests.CleanupActiveEffectConsumesCleanupShellExecutionPlan`，覆盖 cleanup 前 legacy target buffer 被外部清空时，cleanup record 仍消费 shell 中的 `LegacyTargetBuffer` plan。
7. `RuntimeStructuralChangePlanTests` 固化 `RequestedCleanupWorkFlags`、`CreateCleanupWorkFlags`、`ResolveRequestedCleanupWorkFlags` 与 `HasCleanupWork` token。

**后续**：cleanup shell 已承载 requested work plan，cleanup 执行阶段开始按 plan 消费；但 granted ability / modifier / tag / target buffer / duration runtime / final destroy 的具体执行仍在主线程 EntityManager / ECB 语义阶段。下一轮继续推进 cleanup execution system、jobified tick execution、chunk component skip 或 store-only active effect lifecycle。
