# 04 当前进度状态

本目录维护跨轮接力快照。当前路线根入口统一为 `../README.md`。

`04-当前进度状态` 是最新交接入口，不是长期事实 owner。迭代摘要中的重要发现必须按 [规范手册](../规范手册.md) 第6节反哺到 `00/01/02` 或 `迭代记录/`。

## 文件索引

| 文件 | 职责 |
|---|---|
| [当前窗口](当前窗口.md) | 当前阶段、当前推荐任务、注意事项 |
| [迭代摘要](迭代摘要.md) | 本轮 Agent 一手交接摘要、发现、反哺清单和下一轮建议阅读 |
| [最近验证摘要](最近验证摘要.md) | 最近与当前任务相关的验证摘要 |

## 维护规则

本目录遵守 [规范手册](../规范手册.md) 第6节（迭代摘要反哺流程），不在此重复。

本目录特有规则：

1. 每轮覆盖当前状态，不追加长历史；长过程进入 `迭代记录/`。
2. `当前窗口` 只回答现在推进到哪里、下一步拿什么、当前注意事项。
3. `最近验证摘要` 只记录最近验证结果、口径和关键数据。
4. 不承载架构结论或任务树全文；对应内容必须写入 `00/01/02` 的 owner 文档。
