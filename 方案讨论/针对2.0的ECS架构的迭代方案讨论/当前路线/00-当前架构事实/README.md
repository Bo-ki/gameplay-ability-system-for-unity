# 00 当前架构事实

本目录维护当前版本的架构事实、核心问题诊断和合规审查。它回答"当前版本到底长什么样、问题在哪里、哪些事实已经成立"。

## 目录索引

| 文件/子目录 | 类型 | 职责 |
|------------|------|------|
| [_index.md](_index.md) | 总看板 | 架构事实摘要、核心问题看板、总诊断、开放点摘要 |
| [维护规范.md](维护规范.md) | 规范 | 问题生命周期、证据等级、ISSUE 模板、时效性维护 |
| [架构事实/](架构事实/_index.md) | 事实 | Runtime 主链、Definition 配置、架构图、模块索引 |
| [核心问题诊断/](核心问题诊断/_index.md) | 问题 | 单问题诊断文档（ISSUE-001 ~ 011）|
| [合规审查/](合规审查/_index.md) | 审查 | DOTS 代码合规缺陷清单（按 P0/P1/P2 严重度）|

## 快速入口

- **想了解当前有什么问题** → [_index.md](_index.md) 核心问题看板
- **想了解问题诊断流程和模板** → [维护规范.md](维护规范.md)
- **想了解当前架构事实** → [架构事实/_index.md](架构事实/_index.md)
- **想查看合规缺陷** → [合规审查/_index.md](合规审查/_index.md)

## 边界

1. 只写已经对照当前代码、验证记录或当前 profile 成立的事实。
2. 不写目标态设想（目标态进入 `../01-目标态架构共识/`）。
3. 不写任务状态（任务状态进入 `../02-主线任务树/`）。
