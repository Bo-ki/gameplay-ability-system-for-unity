# 模块索引

## Runtime 模块

| 路径 | 当前职责 | 备注 |
|---|---|---|
| `Assets/GAS/Runtime/Ability` | Ability config / runtime component | 当前 Ability commit/lifecycle 已有 contract |
| `Assets/GAS/Runtime/AbilitySystem` | Facade / binding / ASC 接入 | 外部写入和 observation 读取边界 |
| `Assets/GAS/Runtime/Attribute` | Attribute 数据与 helper | 后续需接 AttributeDelta |
| `Assets/GAS/Runtime/Cue` | Cue request / presentation 边界 | 不作为 gameplay 权威 |
| `Assets/GAS/Runtime/Definition` | DefinitionTable / Generated / Bake / Integration contract | 配置链主入口 |
| `Assets/GAS/Runtime/Effect` | GE config / spec / context / runtime state | 旧 lifecycle pipeline 主要迁移对象 |
| `Assets/GAS/Runtime/Event` | GameplayEventBus / Replay / facts | Observation 与 typed fact 分界需继续清晰化 |
| `Assets/GAS/Runtime/System` | Runtime ECS systems | 当前热路径和调度主区域 |
| `Assets/GAS/Runtime/Tag` | Tag mask / requirement | 统一 tag requirement evaluator |
| `Assets/GAS/Runtime/Debugger` | Runtime debug/log 相关能力 | 需要升级为 Runtime Core Debugger baseline |
| `Assets/GAS/Runtime/Demo` | 当前仍承载 Headless / AutoChess demo | 这是错误边界；Demo 业务需要迁移到 `Assets/AutoChessDemo` |
| `Assets/AutoChessDemo` | 目标 AutoChess 验收 Demo 根目录 | 当前目标目录，需后续建立并迁移 |
