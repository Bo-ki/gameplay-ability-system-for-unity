## 当前路线口径

1. 目标态架构共识是主 Spec owner。
2. 主线任务树同时承担原迭代路线总览职责；路线原则、AM 阶段、当前推荐任务都维护在 `02-主线任务树/README.md` 和对应任务节点内。
3. 不再维护独立 `来源索引/` 文件夹；来源定位直接写入对应 Spec 的 `历史方案定位` 章节。
4. 不再维护独立 `路线总览/` 文件夹；路线总览已经融合到主线任务树看板。
5. 当前架构事实负责诊断当前问题，历史方案里的旧问题判断只能作为旧快照证据。
6. Goal 模式推进时，以任务树节点作为 prompt 单元；若上下文不足，先补 Spec 或任务节点，再进入实现。
7. Unity DOTS 官方文档参考是当前路线级官方依据库，不再隶属于目标态 Spec；DOTS 相关任务必须先读取 `UnityDOTS官方文档参考/README.md` 和相关单主题文档，再通过 `UnityDOTS官方文档参考/主题/21-官方文档覆盖与流程闭环.md` 的 `ODF-*` 规则证明官方结论已经进入行动报告、任务树、验收和反哺流程。
8. 每 5 轮主要迭代或每次路线重排后，复核"历史方案吸收矩阵"；发现未吸收但有价值的设计信号时，先回写对应 Spec 的 `历史方案定位`，不直接在矩阵中展开新设计。
