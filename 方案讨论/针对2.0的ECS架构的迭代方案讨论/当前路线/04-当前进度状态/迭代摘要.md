# 迭代摘要

## 当前最新索引

当前最新代码小闭环是 `GAS ECS Runtime - Runtime Core 重构 - Instant Spec Evaluation 迁移`（任务ID：`T1-RuntimeCore-AM3`）的 EventBus legacy callsite writer 迁移。本轮在上一轮去 ThreadStatic 的基础上，把 `SApplyGameplayEffectRequest`、`SEffectCommandSpecStreamPhases` 和 `EffectMagnitudeResolver` 中的 AM3 / legacy instant EventBus 写入改为复用显式 `GameplayEventBusWriter`；这只是继续收缩 `ISSUE-011` 的 EventBus legacy callsite，不代表全局 EventBus singleton 已完成拆分。`EffectRuntimeUtility`、`SExecutionCalculation*`、其它静态 `EventBusHelper.Enqueue*`、NativeStream / owner-local fact fan-in 和 NativeArray-on-component 仍待后续任务。本轮不回到 AutoChess 业务拆分。

## 最新本轮范围（T1-RuntimeCore-AM3 EventBus legacy callsite writer 迁移）

Runtime Core AM3 / ISSUE-011：本轮只处理 AM3 simple instant / legacy instant bypass 相关 EventBus 写入调用点，目标是让同一 apply / projection 流程共享一个显式 writer/context；不拆 `CGameplayEventBus` singleton，不切 `NativeStream`，不迁移所有 legacy `EventBusHelper.Enqueue*` 调用，不推进 AutoChess 业务拆分。

## 最新本轮产出（T1-RuntimeCore-AM3 EventBus legacy callsite writer 迁移）

1. `SApplyGameplayEffectRequest` 在 `OnUpdate` 中创建一次 `GameplayEventBusWriter`，并通过 `ref` 传入 `ProcessTargets` / `ProcessTarget` / legacy instant bypass helper；`CEffectContext.ContextId` 统一从 writer 分配，无 writer 时才使用本地 fallback。
2. `TryApplyLegacyInstantModifierBypassDirect` 改为显式打开 / dispose writer，legacy direct bypass 的 `EffectInstanced`、`CueRequested`、`AttributeChange`、`GameplayEffectApplied` 事件不再直接调用静态 `EventBusHelper.Enqueue*`。
3. `EffectMagnitudeResolver` 增加 writer 版 `ResolveModifiers` / `ResolveMagnitude` / `ResolveExecutionCalculation` / `EnqueueMagnitudeFact`，让 execution calculation missing fact 复用外层 EventBus writer 的 sequence snapshot。
4. `SEffectCommandSpecStreamPhases` 中 attribute typed fact bridge 与 Cue-on-Apply projection 改为显式 writer 写 legacy `BGameplayEvent` / `BCueRequest`，并在 `finally` 中 dispose，避免跨系统投影时重复单条写回 EventBus state。
5. `GameplayEffectRequestWriterTests` 扩展 legacy instant bypass 序列断言，覆盖同一 writer 下 `BGameplayEvent.Sequence` 连续分配和 `CGameplayEventBus.NextSequence` / `NextContextId` flush 结果。
