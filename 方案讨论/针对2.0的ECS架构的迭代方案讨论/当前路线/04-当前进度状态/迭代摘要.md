### EventBus ThreadStatic 去 ambient 化（AM3 / ISSUE-011）

**产出**：
1. `EventBusHelper` 删除所有 `[ThreadStatic]` 字段，新增 `GameplayEventBusWriter`（显式持有 event bus entity / frame / snapshot）
2. `SAbilityCommit`、`SAbilityStateCleanup` 迁为显式 writer
3. 删除未显式使用 writer 的旧 `BeginGameplayEventBatch` Runtime 调用
4. `CommandEventBridgeContractTests` 覆盖 writer 在结构变化后不复用旧 buffer handle

**API 选型**：继续使用 singleton `DynamicBuffer` 作为迁移期 proof-only 承载；拒绝 `NativeStream` / per-owner buffer 因为当前为单线程 observation 小闭环。重新选型触发条件为 x50/x1000 profile 出现 global buffer pressure、outbox count > fact count、cursor lag。

**验证**：`dotnet build` Runtime + Tests 通过。
