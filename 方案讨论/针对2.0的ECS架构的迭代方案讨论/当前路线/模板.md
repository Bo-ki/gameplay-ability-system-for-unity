## 三级任务提示词模板

```text
任务名：
状态：
父节点：

当前问题：
- 来自 00-当前架构事实/核心问题诊断.md 的问题摘要。

目标态参考：
- 01-目标态架构共识/xxx.md

历史方案参考：
- 当前路线/历史方案参考/方案N.md 的哪些设计信号可参考。
- 明确哪些内容不可直接照搬。

目标 / 目的：
- 本任务要改变的架构事实。

非目标：
- 明确本任务不处理的内容。

执行范围：
- 可能涉及的目录、System、组件、测试文件。

执行细则：
- 命名、调度、数据流、边界和禁止绕过的 contract。

验收标准：
- 可观察结果。

测试链路：
- dotnet build / Unity test / headless demo / profile / 文档检查。

交还内容：
- 代码、测试、文档和验证摘要。
```
