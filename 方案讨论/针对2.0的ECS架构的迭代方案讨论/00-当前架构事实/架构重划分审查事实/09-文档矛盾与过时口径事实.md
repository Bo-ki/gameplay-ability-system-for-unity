## 判定口径

1. 单一职责治理不等于只拆文件；命中同主题重复正文时，优先选择唯一正文 owner 并合并，旧入口降权为索引或兼容跳转。
2. 渐进式披露不等于保留多份同义长文；根 README 和索引只负责导航、职责、读取顺序和验收入口。
3. 目标态文档只写理想架构 contract、禁止方向、API 选型和验收门槛；当前代码事实、行号、codedb 数字、验证日志和迁移进度都属于 `00/04`。
4. 当前事实文档可以引用目标态 Spec 作为判定标准，但不能复制完整理想代码骨架或替目标态定义新 contract。
5. 任务树只写消费门、领取条件、交还包和验证链；旧 AM / Chain / Export proof 只能作为历史证据，不能恢复为当前入口。
