# 模块索引

> 上次更新：2026-06-02 | 事实源：当前代码树，不采用过期路线文档作第一事实源

## Runtime 模块

| 路径 | 当前职责 | 当前事实 |
|---|---|---|
| `Assets/GAS/Runtime/General` | `GASManager`、World 创建、singleton entity、基础 helper | `GASManager.Initialize()` 创建 `EX_GAS_World`，并通过 `GASSystemScheduleContract` 注册 5 段 GAS 主链 |
| `Assets/GAS/Runtime/System/SystemGroup` | 物理调度域与 contract | 当前真实主链是 `FramePrepare -> CommandResolve -> CoreSimulation -> StructuralCommit -> BoundaryProjection` |
| `Assets/GAS/Runtime/AbilitySystem` | ASC facade、binding、request entity 入口 | `ASCCommandGateway` 仍直接创建 request entity，是当前 Runtime Boundary 的 P0 风险 |
| `Assets/GAS/Runtime/Ability` | Ability config、runtime actions、ability state 数据 | Ability command/activation 已接入 command resolve；部分 runtime action 仍依赖 `EntityManager` |
| `Assets/GAS/Runtime/Effect` | GE config、command/spec stream、active effect store、effect utility | command/spec/delta/fact 已形成迁移链；singleton DynamicBuffer 仍是 proof-only carrier |
| `Assets/GAS/Runtime/Attribute` | Attribute value、modifier、dirty/change event 数据 | generated `GASAttributeSetReduceApplySystem` 写 `AttributeModifierBuffer`，`AttributeRecalculateSystem` 仍在 CoreSimulation |
| `Assets/GAS/Runtime/Tag` | tag mask、requirement、tag query | 运行时 tag helper 仍含托管 `Dictionary`，不适合作为 Burst hot path 终局 |
| `Assets/GAS/Runtime/Cue` | Cue config、managed cue runtime、presentation bridge | Cue 位于 BoundaryProjection；managed cue 是表现边界，不应反馈 CoreSimulation |
| `Assets/GAS/Runtime/Event` | legacy EventBus、typed fact projection、presentation/replay/debug 输出 | typed fact 与 legacy EventBus 迁移期并存；Observation 成本需与 CoreSimulation 拆开报告 |
| `Assets/GAS/Runtime/Definition` | Definition table、generated adapter、runtime catalog blob 类型 | `GASDefinitionCatalogBlob` 已进入 generated runtime；旧 DefinitionTable 仍是 managed summary/diagnostic 层 |
| `Assets/GAS/Runtime/Debugger` | runtime snapshot、structured log、official tool diff | `ToEntityArray` 主要留在 debugger/observation 路径，不再是旧 hot path 主诊断 |

## Generated Runtime 模块

| 路径 | 当前职责 | 当前事实 |
|---|---|---|
| `Assets/GAS/Generated/CodeGen/Runtime/RuntimeSystemRegistration.gen.cs` | generated system 注册入口 | 通过反射被 `GASSystemScheduleContract.TryRegisterGeneratedRuntimeSystems()` 调用 |
| `RuntimeAbilityActivation.gen.cs` | generated ability catalog commit | 注册到 `GASCommandResolveSystemGroup` |
| `RuntimeEffectInstant.gen.cs` | instant GE spec build 与 attribute reduce | 注册到 `GASCoreSimulationSystemGroup` |
| `RuntimeActiveEffect.gen.cs` | command normalize、active effect mutation/tick/remove | 注册到 `GASCoreSimulationSystemGroup`；仍含 `SystemAPI.Query`、buffer for loop、`Complete()` |
| `DefinitionCatalog.gen.cs` / `RuntimeDefinitionGlue.gen.cs` | catalog lookup 与 runtime glue | 读取 `GASDefinitionCatalogBlob`，不是运行时 JSON/Excel 查询 |

## AutoChessDemo 模块

| 路径 | 当前职责 | 当前事实 |
|---|---|---|
| `Assets/AutoChessDemo/GameRoom` | 房间、玩家、阵容、棋子和规则码定义 | Demo 业务入口，不属于 Runtime Core |
| `Assets/AutoChessDemo/Battle` | 对局契约、战斗编排、session、result、日志翻译 | `AutoChessBattleManager`/`Session` 编排真实自走棋业务流 |

## 当前主风险索引

1. `ASCCommandGateway` / demo bridge 仍能绕过统一 command sink 同步创建 entity。
2. generated runtime 已是执行链一部分，必须纳入 DOTS 审查，不能只审 handwritten Runtime。
3. `GEEffectCommandStreamComponent` singleton owner 承载 command/spec/delta/fact，是 proof 形态，不是 scale-ready 终局。
4. `GASManager.EntityManager` 是全局入口，初始化/authoring/prototype 可容忍，Runtime hot path 需要继续收口。
5. `GasRuntimeDebugger`、structured log、official diff 是证据工具，但 observation 成本不能混进 CoreSimulation 热路径结论。
