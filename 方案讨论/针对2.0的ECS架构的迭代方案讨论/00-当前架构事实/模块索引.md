| `Assets/GAS/Runtime/Debugger` | runtime snapshot、structured log、official tool diff | `ToEntityArray` 主要留在 debugger/observation 路径，不再是旧 hot path 主诊断 |

## 当前主风险索引

1. demo bridge 仍有直接 `EntityManager` 迁移风险；`ASCCommandPort` request entity 旧链路已退场但必须防回流。
2. ASC command resolve 与 generated runtime 已是执行链一部分，必须纳入 DOTS 审查，不能只审 handwritten Runtime；owner-local marker mask、ability commit/auto-end、ability lifecycle request aggregation、attribute owner marker aggregation、instant spec/reduce、active mutation chunk apply、pending AttributeDelta chunk apply、explicit remove pending mask、execution output applied chunk applicator 和 seed scratch 移除等已修复项需要 static validation 防回流，`Complete()` 清零不等于 singleton stream / stream fallback / SourceAttribute snapshot lane 已合格。
3. `GEEffectCommandStreamComponent` singleton owner 承载 command/spec/delta/fact，是 proof 形态，不是 scale-ready 终局。
4. `GASManager.EntityManager` 与 `GASRuntimeShell` 是全局入口，初始化/authoring/prototype/diagnostics 可容忍，但 Shell capability 必须分级，Runtime hot path 和业务层需要继续收口。
5. `GasRuntimeDebugger`、structured log、official diff 是证据工具，但 observation 成本不能混进 CoreSimulation 热路径结论。
