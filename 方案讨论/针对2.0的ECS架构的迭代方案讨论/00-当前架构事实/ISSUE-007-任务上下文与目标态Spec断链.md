# ISSUE-007 任务上下文与目标态 Spec 断链

> 最近复核：2026-06-06 | 状态：Active | 严重度：P2

## 当前结论

当前最主要的断链风险不是没有 Spec，而是旧事实、旧目标态、旧任务口径在文档中回流，覆盖了现实代码。用户已明确要求以现实代码为第一性参考。

## 当前风险

1. 文档仍可能引用已不存在文件。
2. Contract/Plan 文件容易被误写成完成证明。
3. 旧 group 名称容易被误写成当前主链。
4. AutoChessDemo 的旧 Headless 状态容易误导后续任务。

## 当前规则

1. 当前事实必须先查代码。
2. 目标态必须区分“希望如此”和“代码已如此”。
3. ISSUE 更新必须写“已缓解部分”和“仍成立风险”。
4. 涉及 DOTS 官方规则时，后续目标态方案再对照 `方案讨论/UnityDOTS官方文档参考/主题` 检验。

## 退出条件

1. `00-当前架构事实` 不再含已不存在文件作为当前事实。
2. `01-目标态架构共识` 的每条目标都能追溯到当前事实差距。
3. 新任务创建前先声明事实源和代码证据路径。
